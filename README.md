# terrain-graph

ハイトマップとマスクをノードグラフで生成・加工し、PBR テクスチャと組み合わせて
マテリアルと地形をオーサリングするツール。

material-mixer（Quixel Mixer 相当のレイヤー合成ツール）からのフォーク。
レイヤースタック方式は廃止済みで、**合成はノードグラフで組み立てる**
（グラフの仕組みは terrain-editor から移植。合成規則はレイヤー時代と同じ）。

- 言語: C++20
- ビルド: CMake + vcpkg（manifest モード）
- グラフィックス API: DirectX 12（シェーダモデル 6.6、bindless）
- UI: Dear ImGui（docking ブランチ）
- 対象 OS: Windows のみ

## いまできること

- **ノードグラフ合成**: サーフェス / シェイプ / 水面をノードとして「グラフ」パネルで
  繋ぎ、出力ノードへ届いた「下地」チェーンが**ハイトベースブレンド**で合成される。
  単純なアルファ合成ではなく高さの大小で上下関係が決まるため、
  「岩の隙間に砂が溜まる」といった表現が作れる。
  **ノードを選ぶと、そのノードまでの結果がビューポートに出る**（選択を外すと出力まで）。
- **チャンネル**: BaseColor / Normal / Surface（Roughness・Metallic・AO）/ Height。
  ノードごとに書き込むチャンネルを選べる。
- **ノードの入力**: 定数、ノイズ（fBm / 尾根状 / セル状）、テクスチャ。
  法線はハイトの勾配から自動生成される（法線テクスチャの指定も可）。
- **マテリアル**: PBR のマップ一式に名前を付けて持ち、ノードはそれを 1 つ参照する。
  サムネイル付きの一覧から選べる。
  PNG / TGA / JPG / **EXR** を読み込め、Megascans の `_ORD` のように
  1 枚へ詰めたテクスチャもチャンネル指定で使える。
- **マスク生成**: 定数・ノイズ・テクスチャに加えて、
  **下地の高さ・傾斜・曲率・窪みからマスクを作れる**。
  「窪みにだけ苔を生やす」「急斜面にだけ岩を出す」といった指定が書ける。
  カーブ、レベル調整、反転も可能。
- **PBR プレビュー**: GGX 直接光 + IBL（分割和近似）。球 / 平面 / キューブ。
  **ディスプレイスメント**（`変位量`）でハイトを形状に反映でき、シルエットまで変わる。
  **テセレーション**（画面上の辺の長さで適応的に分割）と
  **影**（シャドウマップ）も切り替えられる。
  ビューポート左上のボタンで、合成した各チャンネル（ベースカラー /
  法線（接空間・ワールド）/ ラフネス / メタルネス / AO / ハイト）や
  ワイヤーフレームをそのまま確認できる。
- **物理カメラの露出**: 絞り・シャッター・ISO から EV100 を求める方式と、EV 直接指定。
  トーンマップは ACES / Reinhard / なし。
- **被写界深度**: ビューポート専用のポストエフェクト。
  **焦点距離はカメラ、F 値は露出からそのまま使う**ので、レンズの指定が二重にならない。
  ピント面は既定で注視点。絞りの形（円 / 三角 / 六角 / 八角）でボケの形が変わる。
  トーンマップの前に線形 HDR へ掛けるので、明るい点がそのまま玉ボケになる。
- **ペイントマスク**: ビューポート上でブラシを引いてマスクを直接描ける。アンドゥ / リドゥ付き。
- **環境**: 天球アセット（手続き的な空 / Radiance HDR）。複数を持って切り替える。背景表示。
- **ステータスバー**: 画面下端に直近の通知（保存した、読み込めなかった など）と、
  いま何を持っているか（プロジェクト名 / 各一覧の数 / 合成解像度 / FPS）を出す。
- **保存**: プロジェクト (`.tgproj`) にグラフ・マテリアル・テクスチャの参照・
  ペイントマスク・プレビュー設定をまとめて保存できる。
  マテリアルは単体ファイル (`.tgmat`) として書き出し、別のプロジェクトへ持ち込める。
  旧形式（レイヤー方式の `.tgproj` や material-mixer 時代の `.mmproj` / `.mmmat`）も
  読み込め、レイヤーは同じ見た目のままノードのチェーンへ移行される（書き出しは新形式のみ）。
  ファイルメニューには最近使ったプロジェクトの履歴（最大 10 件）も出る。
  形式は [docs/reference/file-format.md](docs/reference/file-format.md) を参照。
- **書き出し**: 合成結果を画像として書き出せる（`ファイル > テクスチャを書き出す…`）。
  **プレビューの合成解像度とは独立に解像度を選べる**（最大 8192）。
  チャンネルの詰め方は 個別 / ORD（AO・ラフネス・ハイト）/ ORM（AO・ラフネス・メタルネス）。
  ハイトは段差が出ないよう EXR（float）で出す。

未実装: マスク生成のノード化、地形。
詳細は [docs/plan/plan.md](docs/plan/plan.md) を参照。

## 必要なもの

| 項目 | 確認済みの構成 |
| --- | --- |
| Visual Studio | 2026 Community (18.7) — MSVC 14.51 |
| Windows SDK | 10.0.26100.0 |
| CMake | 4.3 以上（`Visual Studio 18 2026` ジェネレータ対応版） |
| vcpkg | `C:/vcpkg` に導入済み |
| GPU | Resource Binding Tier 3 と シェーダモデル 6.6 に対応したもの |

vcpkg のパスは `VCPKG_ROOT` が設定されていればそれを、なければ `C:/vcpkg` を使う。
どちらも無い場合は構成時にエラーになる。

## ビルド

```powershell
cd D:\GitHub\terrain-graph
cmake --preset x64
cmake --build --preset x64-release
```

構成プリセットは `x64` の 1 つだけで、Debug / Release はビルドプリセットで切り替える
（Visual Studio ジェネレータのマルチコンフィグ構成のため）。

```powershell
cmake --build --preset x64-debug     # デバッグレイヤー + GPU ベースバリデーション付き
cmake --build --preset x64-release
```

初回は vcpkg が依存をビルドするため数分かかる。2 回目以降はキャッシュが効く。

## テスト

```powershell
ctest --test-dir build -C Debug --output-on-failure
```

UI の相互作用（ドラッグ&ドロップ、ホバー）とアンドゥ履歴のテスト。
ImGui へマウスイベントを注入して確かめるので、GPU もウィンドウも要らず一瞬で終わる。

**`--screenshot-ui` では確認できない操作を押さえるためのもの。**
この種の不具合は壊れても画面に何も出ないため、手で気づくのが難しい
（実際、ドラッグ&ドロップは長らく動いていなかった）。

## 実行

```powershell
$exe = "D:\GitHub\terrain-graph\build\bin\Release\terrain_graph.exe"
Start-Process -FilePath $exe -WorkingDirectory (Split-Path $exe)
```

作業ディレクトリを exe の場所にすること。UI のレイアウトが
`terrain_graph_imgui.ini` としてそこに保存される。

> **シェーダはソースツリーを直接参照する。**
> `shaders/` の絶対パスが構成時に実行ファイルへ焼き込まれるため、
> exe 単体を別マシンへ持っていっても動かない。
> 起動したままシェーダを編集して即反映できる開発の都合を優先している。
> 環境変数 `TG_SHADER_DIR` で参照先を上書きできる。

### コマンドライン

```
terrain_graph.exe [--project <path>] [--save-project <path>]
                   [--hdri <path>] [--texture <path>]...
                   [--screenshot <path>] [--screenshot-ui <path>]
                   [--screenshot-frame <n>]
```

| オプション | 内容 |
| --- | --- |
| `--project <path>` | 起動時にプロジェクト (.tgproj) を開く |
| `--save-project <path>` | 指定フレームまで描いてプロジェクトを保存し、終了する（開発用） |
| `--hdri <path>` | 起動時に Radiance HDR (.hdr) を既定の天球へ割り当てる |
| `--export <dir>` | 数フレーム描いてから合成結果を画像へ書き出して終了する |
| `--texture <path>` | 起動時にテクスチャライブラリへ読み込む（繰り返し指定可） |
| `--screenshot <path>` | 指定フレームまで描いてビューポートを PNG に書き出し、終了する |
| `--screenshot-ui <path>` | 同じく、UI 込みのウィンドウ全体を PNG に書き出して終了する |
| `--screenshot-frame <n>` | 書き出すフレーム番号（既定 8） |

`--screenshot` / `--screenshot-ui` は画面キャプチャに頼らず結果を確認するための開発用オプション。
リモートデスクトップ経由や自動確認で使う。

### パネル

- **マテリアル**（中央の下・タブ）— PBR のマップ一式に名前を付けたもの。
  サムネイルの一覧から選び、グラフのノードに割り当てる。
  ラフネス / メタルネス / AO / ハイトは「テクスチャ + 読むチャンネル」で指定するので、
  Megascans の `_ORD` のように 1 枚へ詰めたテクスチャをそのまま使える
  （`ORD` 行から AO=R / ラフネス=G / ハイト=B へ一括割り当て）。
  単体ファイル (`.tgmat`) への書き出しと読み込みもここから。
- **天球**（中央の下・タブ）— ビューポートの環境。手続き的な空か HDRI (.hdr) を選び、
  空の輝度（HDRI の較正）と環境光の強さを**天球ごとに**持つ。
  **一覧で選んだものがそのままビューポートに適用される。**
  サムネイルは裏返した球で、内側に環境が貼られた絵になる。
- **テクスチャ**（中央の下・左）— 読み込んだ画像の一覧。PNG / JPG / TGA / EXR。
  解像度・ミップ数・形式・参照数・置き場所を確認でき、名前の変更と削除ができる。
  **サムネイルをマテリアルのマップ欄へドラッグすると割り当たる。**
  EXR はリニアなので、一覧には sRGB へ直した表示用の絵を出す。
- **グラフ**（右・前面タブ）— ノードグラフのエディタ。
  上段が盤面（右クリックで追加 / ピンをドラッグして接続 / Del で削除 /
  中ドラッグでパン）、下段が選択中ノードの設定
  （マテリアル / ハイト / マスク / ペイント / 合成）。
  出力ノードへ繋いだ「下地」チェーンがプレビューになる。
  **ノードを選ぶと、そのノードまでの結果がビューポートに出る**
  （選択を外すと出力まで戻る）。書き出しも見えているものと同じ対象。
- **ビューポート**（中央）— 合成結果を貼ったプレビュー。
  左上のボタンで表示モード（シェーディング / 各チャンネル / ワイヤーフレーム）を切り替える。
  その横の `表示` ボタンで、重ねる情報を切り替える:
  FPS と統計（右上。ドローコール / 頂点 / 三角形、テセレーション中はパッチ数）、
  ハイトの範囲（height 0 / 0.5 / 1 の位置を示す枠。平面のみ）。
  左下の座標軸ギズモは右手系 Y-up（X = 赤 / Y = 緑 / Z = 青）。
- **プレビュー設定**（右・タブ）— 形状、合成結果の使用可否、UV スケール、変位量、
  テセレーション、合成解像度、カメラ（焦点距離）、被写界深度。
- **ライティング**（右・タブ）— ライト（影のオンオフを含む）、露出、
  環境（IBL）の見え方（背景の表示とぼかし）、トーンマップ。
  **空そのものの設定は「天球」パネルにある。**
- **情報**（右・タブ）— フレームレート、解像度、合成のレイヤー数とタイル数、
  ペイントマスクの枚数と履歴の段数、PSO キャッシュ数（表示専用）。
- **ステータスバー**（下端）— 左に直近の通知とモード、右にプロジェクト名と
  ノード / マテリアル / テクスチャの数、合成解像度、FPS。

配置を崩してしまったら `ウィンドウ > レイアウトをリセット` で既定へ戻せる。
`ウィンドウ > 設定` にアプリ側の設定を置いてある。

- **UI の拡大率** — 既定は 100% 固定。「スケール追従」を入れると Windows の
  表示スケール（150% など）に合わせて文字と部品が大きくなる。
  拡大率を直接選ぶこともできる（100 / 125 / 150 / 200%）。
  **ウィンドウの大きさも同じ倍率になる**（150% なら 2880x1620）ので、
  作業面積は変わらず文字と部品だけが大きくなる。
- **ウィンドウ** — `既定の大きさに戻す` でクライアント領域を既定（1920x1080 × 拡大率）へ戻す。
  録画やスクリーンショットの解像度を揃えるため、実ピクセルで固定している。
- **表示** — 垂直同期、**FPS 上限**、**背面のときの FPS 上限**、
  シェーダのホットリロード、背景色。
  背面のときは既定で 10fps に落とす。見えていない絵に GPU を回し続けないため。
  完全には止めないので、シェーダのホットリロードは効いたまま。

設定は `%LOCALAPPDATA%/terrain-graph/settings.json` に保存される。

### 合成の勘どころ

**マスクは不透明度として高さと同じ土俵で競合する。** 重みは
`a = 下地の高さ + (1 - マスク)`、`b = ノードの高さ + マスク` の比較で決まる。

- マスクを 1.0 にすると高さに関係なく全面を覆う。
- 双方のマスクが 0.5 のとき、高さの大小がそのまま勝敗になる。
  このとき上のノードの**基準の高さ**が「溜まる水位」として働く。
- **境界の柔らかさ**を 0 に近づけると硬い置き換え、大きくすると高さの影響が薄れる。

起動直後と `ファイル > 新規` は、「ベース → 出力」だけのグラフから始まる
（ただの球が既定の背景に見えるだけ）。ノードを足してチェーンへ繋いでいく。

```
src/
  app/          アプリ本体、エントリポイント、UI パネル
  graph/        ノードグラフ（データモデル、レイヤー列へのコンパイル）
  compositor/   レイヤースタックの定義、GPU 評価器、テクスチャ / マテリアル / ペイントマスク
  core/         ログ、Win32 ウィンドウ、画像入出力、ファイル選択ダイアログ

  renderer/     PBR プレビュー描画、カメラ、メッシュ、IBL 環境
  rhi/          DX12 ラッパ（device, descriptor, PSO, resource, shader）
  ui/           Dear ImGui の統合、テーマとプロパティ行
shaders/        HLSL（実行時に DXC でコンパイル、ホットリロード対応）
docs/
  plan/         goals / plan / progress — 進捗管理の入口
  design/       実装の設計ガイド
  reference/    設計資料、仕様メモ、調査資料
```
