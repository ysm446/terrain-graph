## 未リリース

### 2026-09-03 16:00 — 堆積が細かい凹凸をならすようになった

- **土砂が積もった所では、下にあった細かい凹凸が埋まる**ようにした。
  これまでは解析グリッドの結果を差分で足すだけだったので、厚く積もった所でも
  下地の礫がそのまま出ていて、砂利の上に泥を塗ったように見えていた。
  厚みぶんだけ細部を 0 へ寄せるので、**出っ張りの頂上は動かず、窪みが埋まり、
  厚く積もった所は平らになる。** パラメータは無い（体積の帳尻が合う形にしてある）。
- **`地形を土砂にする` が入のときの Mask 出力を直した。**
  厚みを「基盤 + 土砂 − 元の高さ」で取るようにしたので、あの設定でも
  「積もったぶん」が出る。これまでは**地形の高さそのもの**が出ていた。

### 2026-09-03 14:00 — Sediment の Mask を実寸で正規化する

- **`基準の厚み`（m、既定 0.5m）を追加した。** 積もった土砂がこの厚みに
  達した所でマスクが 1 になる。これまでは「一番厚い所で 1」だったため、
  少数の分厚い点が基準になって残りが 0 付近へ潰れ、
  **Mask を繋いでもほとんど何も乗らなかった**（実測で 0.5 以上の面積が 0.29%）。
  0 にすれば従来の挙動に戻せる。
- 既存のプロジェクトも新しい既定（0.5m）で読む。
  **回避策としてマスクの白点を下げていた場合は 1.0 に戻すこと。**

### 2026-09-03 12:30 — マスクを被覆率として扱うようにした

- **サーフェスのマスクが 0.5 付近のしきい値としてしか効かなかったのを直した。**
  これまではマスクを高さと同じ土俵で競合させていたため、下地に沿わせた
  レイヤーでは **0.43 以下のマスクがまったく絵に出なかった**。
  Sediment の Mask を繋いでも何も乗らない、という形で出ていた。
- **マスク 0 / 1 の結果は今までと同じ。** 中間の値が、そのレイヤーの起伏の
  高い所から順に出るようになった（シェイプの `weight = mask` とも揃う）。
  既存プロジェクトへの影響は小さい（`data/sample.tgproj` で差の出た画素は 0.2%）。

### 2026-09-03 09:00 — 素材の法線マップの向き（緑の反転）

- **素材の法線マップが Z 方向に反転していたのを直した。** 法線マップには
  OpenGL 規約（緑 = 画像の上向き。Megascans などの既定）と DirectX 規約が
  あり、このアプリの接空間と自前の法線は DirectX 規約に揃えてある。
  **マテリアルに「緑を反転」**（既定は入 = OpenGL）を足し、規約の違いを吸収する。
- 先日タンジェントの符号を直したときに表に出た問題で、
  それ以前は「自前の法線が逆 / 法線マップが正しい」という状態だった。

### 2026-09-03 06:30 — Sediment（堆積）ノードを追加

- **土砂を重力で再分配する「Sediment」ノード**を追加した
  （背景の右クリック。terrain-editor の同名ノードの移植）。
  安息角を超えた斜面から土砂が低い方へ滑り、谷底に厚く積もって尾根が痩せる。
- **「地形を土砂にする」**が入だと入力の地形そのものが崩れる（GeoGen 風）。
  切ると入力は動かない基盤になり、**供給量**で足したぶんだけが流れるので、
  地形の形を保ったまま谷に堆積を作れる。
- 粘性で安息角を決める（0.2 でほぼ平ら、0.5 で 20 度）。
  反復 / 安定化 / 最大ディテールで落ち着き方を調整する。
- 計算グリッドは合成解像度とは別（既定 512）。動いたぶんだけを
  下地のハイトへ足すので、合成解像度で作った細部は残る。

### 2026-09-03 05:20 — メッシュ分割の設定と「ハイト（ローカル）」表示

- **プレビュー設定に「メッシュ分割」**（256 / 512 / 1024）を足した。
  地形の一辺 ÷ 分割数 が 1 マスの大きさで、**形の細かさの上限**になる
  （2048m の地形なら 256 分割で 8m、1024 分割で 2m）。
  テセレーションは画面上で辺が伸びたときしか割らないので、
  引きの絵で細部を出したいときはここを上げる。
- **表示に「ハイト（ローカル）」**を足した。周りの平均を引いた「その場の起伏」だけを
  出すので、標高差 600m の傾きに埋もれていた素材の凹凸が、
  ハイトマップをそのまま貼ったように見える。

### 2026-09-03 03:10 — マスクをノード単位で評価するようにし、Slope / Levels / Blend を追加

- **マスクの評価がノード単位になった。** これまでマスクのノードは
  コンパイル時にレイヤーの設定へ畳み込んでいたが、**ノードごとに 1 枚ずつ
  テクスチャへ焼く**方式に変えた。中間結果が残るので、
  **合流（Mask Blend）**も、同じマスクを 2 か所で使うこともできる。
- **重いノードは、関係ない編集では焼き直さない。** 入力（パラメータ / 上流の
  マスク / そこまでの地形の高さ / 実寸）のハッシュが前回と同じなら、
  前回の結果をそのまま使う。色やラフネスを動かしても川筋は再計算しない。
- **ノードを 3 つ追加**（terrain-editor から移植）。
  - **Mask Slope**: 下地の傾斜を**角度（度）**でマスクにする。
    岩肌を急斜面にだけ出す、雪を平地に限る、といった使い方。
  - **Mask Levels**: 黒点 / 白点 / ガンマ / 反転でマスクを整える。
  - **Mask Blend**: マスク 2 枚を 加算 / 乗算 / 小さいほう / 大きいほう で合成する。
    片方だけ繋いだときは、繋いだほうをそのまま通す。
- どのマスクノードも、**選ぶとマスクのプレビュー**（白黒）になる。
- レイヤーのマスクの「ソース」から `下地の川筋` は選べなくなった
  （川筋はノードとして繋ぐ）。

### 2026-09-02 22:30 — 直接光の陰影が Z 方向で反転していたのを修正 / プレビューを平面だけに

- **平面の陰影が Z 方向だけ反転していたのを直した。** 平面メッシュの
  接空間（従法線）の符号が、その平面の V の向きと逆になっていたのが原因で、
  形は正しいのに「光が反対から当たっているように見える」状態だった。
  ランプ状のハイトに +Z / -Z から光を当てて明るさを測り、修正の前後で
  逆転することを確認している。
- **プレビュー設定の「形状」と「UV スケール」を無くした。**
  地形をオーサリングするツールなので、ジオメトリは平面 1 種類に決め打ちし、
  合成結果は等倍で貼る。球とキューブのメッシュも削除した。
  素材のタイリングはこれまで通りレイヤーの `UV スケール` で行う。
- 古いプロジェクトの `shape` / `materialUvScale` は読み飛ばす（見た目は平面になる）。

### 2026-09-02 21:20 — ライトのギズモを地形の大きさに合わせる

- **L キーのライトギズモが地形の実寸に追従する**ようにした。
  リングと矢印の大きさを平面の一辺（m）の半分から決める。これまでは

### 2026-09-02 21:05 — Heightmap Blur ノードを追加

- **ハイトをぼかす「Heightmap Blur」ノード**を追加した（背景の右クリック）。
  細かいノイズや画像由来のピクセル感、階段状の段差をならす加工で、
  terrain-editor の同名ノードを移したもの（分離型ガウス。GPU で実行）。
- 設定は **半径（m） / 強さ / 反復** の 3 つ。半径は実寸なので、
  合成解像度を変えても効きは変わらない。
- ぼかした形から**法線を作り直す**ので、形と陰影が食い違わない。
  そのぶん、このノードより下で載せた素材の法線ディテールは消える。
  **ハイトの段階（Heightmap の直後）に置き、素材はその後ろに繋ぐこと。**

### 2026-09-02 20:05 — 法線を実寸の勾配から作る（「法線の強さ」を廃止）

- **法線を地形の実寸（m）で計算する**ようにした。ハイト 0〜1 の全幅が標高差、
  出力 UV 0〜1 が地形の一辺なので、その比から `d(高さ m)/d(距離 m)` を求めて
  法線にする。傾きが「その地形が実際に何度か」と一致する。
- **レイヤーの「法線の強さ」を削除した。** 地形をオーサリングするツールに
  なったので、見た目を合わせるための無次元のつまみは持たない。
  法線とディスプレイスメントが必ず同じ形を表すようになり、
  「形にも出て、法線にも出る」二重掛けを手で打ち消す必要も無くなった。
- ハイトマップノードも他のノードと同じ扱いで、実寸の法線が出る。
- **ハイトマップノードの「起伏の強さ」も廃止した**（1.0 固定）。
  画像の 0〜1 がそのままハイトの全幅で、それが何 m かは同じノードの
  「標高差」が決める。振れ幅を決める場所を 2 か所に持たせない。
  古いファイルが別の値を持っていても 1.0 として読む。
- **注意: `起伏の強さ` は「標高差に対する割合」として効く。**
  既存のプロジェクトでディテール素材のハイトを強さ 1.0 前後で載せていると、
  砂利の粒が数十 m の岩になる。素材側の起伏の強さを実寸に合わせて下げること。
- 既存のプロジェクトはそのまま開ける（`normalStrength` は読み飛ばす）。

### 2026-09-02 19:35 — 地形の実寸を Heightmap ノードで指定する / ノード名を英語に

### 2026-09-02 18:41 — 地形スケールに対応し、ハイトマップノードを追加

- **「ハイトマップ」ノード**を追加した（グラフの背景を右クリック）。

### 2026-09-02 15:07 — 平面プレビューの縁が反対側と混ざる問題を修正

- **シェイプノードでハイトマップ（テクスチャ）を読むと、平面の縁が
  反対側の端の高さへ引っ張られて壁が立っていた。** 合成結果を貼るときの

  玉ボケの芯が白く潰れる。HDR のままなら明るいサンプルがそのまま強く出るので、
  ハイライト強調の細工が要らない。
- ピント面は既定で**注視点**（軌道カメラなので、見ているものは常にそこにある）。
  手で距離を決めることもできる。
- 絞りの形は 円 / 三角形 / 六角形 / 八角形。多角形は向きも変えられる。
- **ボケの強さに表示用の倍率を持たせた**（既定 1 = 現実どおり）。
  プレビューは被写体が小さく画角も広いため、現実の式のままだと
  ほぼ全域にピントが合ってしまう（29mm・F1.8・3.2m で錯乱円が 1 画素に届かない）。
- 深度を SRV としても読めるように、深度バッファを TYPELESS で作り直した。
- 設定はプロジェクトの `preview.depthOfField` に保存する。
- **ワールドの 1 単位を 1m と決めた**（[design/rendering.md](design/rendering.md)）。
  これまで単位を決める必要が無かったが、被写界深度が距離を実寸として扱うため確定させた。

  （**Megascans のサーフェスが 2m 角で作られているものが多い**のに合わせてある）。

### 2026-09-01 16:50 — フル解像度エクスポート（M5c）

- **合成結果を画像として書き出せるようにした**（`ファイル > テクスチャを書き出す…`）。
- **書き出しだけの解像度を選べる**（1024 / 2048 / 4096 / 8192）。
  書き出し専用の評価器を指定解像度で作り、タイルに分けて評価してから読み戻すので、
  **プレビューの合成解像度には触らない**（書き出しの前後で画面の見え方が変わらない）。
- チャンネルの詰め方は 3 通り。
  - **個別**: ラフネス / メタルネス / AO を 1 枚ずつ。
  - **ORD**: AO=R / ラフネス=G / ハイト=B（Megascans の並び）。
  - **ORM**: AO=R / ラフネス=G / メタルネス=B（glTF / Unreal の並び）。
- **ハイトは EXR（float）で出す。** 8bit の PNG に落とすと段差が見える
  （stb は 16bit PNG を書けないため、素直に float を持てる EXR にした）。
  8bit で足りるときは PNG にも切り替えられる。
- 形式の変換とチャンネルの詰め替えは `ExportPack.hlsl` が GPU 側でまとめて行う。
  CPU が受け取るのは「そのまま並べれば PNG になるバイト列」だけ。
- ベースカラーは sRGB へ、法線は 0.5 が平坦になる一般的な並びへ直して書く。
- 開発用オプション `--export <dir>` を追加。数フレーム描いてから書き出して終了する。

### 2026-09-01 05:40 — HDRI が真っ黒になる問題を修正

- **HDRI を読み込むと環境が真っ黒だったのを直した。** ファイルは正常で、
  **輝度の単位が合っていなかった**のが原因。
- このアプリは環境を物理量（cd/m²）で扱っている（手続き的な空は 12000 cd/m²、
  太陽は 100000 lux）。一方 **HDRI ファイルは絶対輝度で較正されていない**。
  実測したところ、屋外 HDRI の空は 0.15〜0.2 程度しかなく、
  日中の露出では 3 桁以上足りずに黒く潰れていた。
- **読み込み時に空の輝度を測り、指定した cd/m² へ合わせるようにした。**
  `ライティングと露出 > 環境 (IBL) > 空の輝度`（既定 12000 cd/m² = 晴天）。
  倍率ではなく「空が何 cd/m² か」を指定するので、**どのファイルでも同じ意味**になる。
  スライダーを動かしてもファイルは読み直さない。
- 値はプロジェクトに保存される。
- **画像内の比は変えていない**ので、明暗の関係は元のまま。

- **レイヤーの並べ替えをドラッグ＆ドロップにした。**「上へ」「下へ」ボタンは廃止。

  UI もその面へ 1:1 で載せるので、モニタの表示スケールで作業面積が変わらない。

  UI 込みのウィンドウ全体を PNG に書き出す。画面キャプチャに頼らずに見た目を確認できる。
- UI のルールを [docs/design/design-guide.md](design/design-guide.md) にまとめた。

### 2026-08-31 13:32 — M4b: ペイントマスク（ブラシ）

- マスクの出どころに「ペイント」を追加。ビューポート上でブラシを引いて、
  レイヤーのマスクを直接描けるようになった。
  プロシージャルでは狙えない場所（ここだけ苔、この一筆だけ砂）を指定できる。
- ペイントモード中は左ドラッグで塗り、右ドラッグで消す。
  視点を回すときは Alt + 左ドラッグ。中ボタンのパンとホイールのズームはそのまま。
- **ブラシの半径は画面上の見た目で決まる。** 視点を近づけても遠ざけても、
  UV スケールを変えても、カーソルの円の大きさどおりに塗れる。
- ブラシの強さ・減衰、消しゴム、全消去、全塗り。
- アンドゥ / リドゥ（24 段）。単位は 1 ストローク。
- ペイント解像度を 512 / 1024 / 2048 から選べる。
  変更しても描いた内容は拡大縮小して引き継ぐ（履歴は破棄される）。
- レイヤーを複製するとペイントマスクも中身ごと複製する。
  レイヤーを削除するとペイントマスクも破棄する。

### 2026-08-31 11:13 — M2b: IBL（環境光）

- 環境マップによるライティング（IBL）に対応。
  拡散は irradiance キューブ、鏡面はラフネス別にプリフィルタしたキューブと

  `--hdri <path>` で起動時に HDRI を読み込み、
  `--screenshot <path>` でビューポートを PNG に書き出して終了する。
