# Snow Cover

作成日時: 2026-09-09 11:36
更新日時: 2026-09-09 11:58

厚い積雪と薄雪の被覆を GPU で生成するノード。
既存の Snow とは設定・シェーダ・作業テクスチャを共有しない。
山頂保護や最低残雪量など、原典にない機能は追加しない。

## 接続と出力

| ピン | 意味 |
| --- | --- |
| Base | 下地の地形。未接続なら評価しない |
| Mask | 降雪量の分布。未接続は全面 1。移動後の雪の範囲を制限するマスクではない |
| Result | 厚い積雪を加えた地形。薄雪だけでは高さを変えない |
| Cover | 厚い雪の二値被覆と薄雪の被覆の最大値。0〜1 |
| Depth | 仕上げ後の雪深。単位は m。1 を超える値も保持する |
| Flows | 最終解像度の段で発生した流動量をセル幅で割った値。0〜1 には正規化しない |

Result を Surface の Base へ、Cover を Surface の Mask へ繋ぎ、
Surface に雪のマテリアルを設定する。Snow Cover 自身は白い色を塗らない。
Depth / Flows を材質のマスクとして使う場合は Mask Levels などで範囲を調整する。
HDA のフィールド名と表示・出力の切り替えは、これらの出力ピンと既存のプレビューで扱う。
入力フィールドを削除する Houdini 固有の項目は、非破壊のノード接続では不要。

## 原典から移した処理

1. 降雪線・降雪マスク・風向から降雪量を作る。
2. 厚い積雪が有効なら `降雪深 × 1.01 × 降雪量` を加える。
3. 粗い格子から元の解像度へ、雪の厚みを拡大して各段の元地形へ戻す。
4. 各段で周囲 8 方向の雪面と流動量の差から雪を移動する。
   軸方向 0.7、斜め 1、更新係数 0.17 を原典どおり使う。
   雪面を基盤より下げず、勾配方向のサンプルから最大傾斜を制限する。
5. 最後に `降雪深 × 0.01 + 0.01 m` と `融雪 × 降雪深 × 2` を除く。
6. 薄雪は元地形上で別に生成する。降雪マスクを移流し、傾斜・曲率・ノイズで
   付着を判定する。厚い雪の Cover と最大値で合成する。

最大傾斜は、旧 Snow の安息角とは違う。8 近傍の安定化はこの角度以下でも働く。
風は斜面の法線との内積で降雪量を補正するもので、風による雪の輸送や遮蔽の解析ではない。
原典同様、傾斜制限・仕上げの除雪は質量保存ではない。

## 実装上の対応

- 高さは計算中だけ m。最終的にアプリの正規化 Height へ戻す。
  降雪線の標高 0 は `Height = 0.5` の基準面に合わせる。
- 合成解像度を最終格子にする。多段解像度の段数は
  `特徴サイズ × 基準スケール / セル幅` から求め、最初の段の反復に端数を反映する。
- 領域はアプリの正方形グリッドを維持し、粗格子はセル平均、拡大は線形補間とする。
  Houdini のパディングと Gaussian resample の画素単位の一致は保証しない。
- Dusting が使う Fluvial Advection の組み合わせ（Smooth、摩擦 1、速度 1、
  粒子密度 0.1、最大角 60 度、pooling 無効）を専用に実装する。
  公開するのは元 Snow Base の流路長・流量補正・移流強度・値の保持率。
- 元 Advection の並行した非 atomic 書き込みを再現すると GPU の実行順に依存する。
  移動ステップごとに元の値を読み、粒子が提案した値を固定小数の atomic 加算で集計する。
  同じセルでは平均値を `1 - (1 - 強度)^粒子数` で混ぜ、流動量を加算する。
  したがって元 HDA と数値が完全一致する移植ではない。
- Houdini の `noise()` の代わりに連続 3D gradient noise を使用する。
  スケール・粗さ・オクターブ・振幅の操作は移すが、模様の乱数列は一致しない。
- 降雪線カーブは最大 8 点。一定・線形・smooth 補間を備える。
- `normalize(0)` と幅 0 の角度・標高遷移は、平面やゼロ設定でも NaN を出さない形にする。
- 原典と同様に細部は最終解像度に依存する。プレビューと書き出しで解像度を変えれば、
  雪の細部や薄雪の粒子の通り道は変わる。

## 保存・評価

ノードの kind は `snowCover`、設定は `layer.snowCover` に保存する。
全設定・カーブをキャッシュキーへ含め、Undo / Redo は既存の設定スナップショットを使う。
Cover / Depth / Flows は当該ノードの評価直後に焼き、次の Snow Cover が
作業テクスチャを再利用しても先行ノードのマスクを保持する。
無効なノードの補助出力は 0。作業リソースは遅延解放し、各パスに UAV バリアを入れる。

関連実装: `shaders/CompositeSnowCover.hlsl`、`MaterialEvaluator::ApplySnowCover()`。

## 検証

- `cmake --preset x64` / `cmake --build --preset x64-debug` と既存テストを実行。
- 全 11 エントリを DXC の `cs_6_6` でコンパイル。
- グラフの入力未接続、専用設定、3 種の補助出力の接続をテスト。
- GPU の 2048² 書き出しで、平面へ 1 m 降らせると 0.989997 m の雪深になることを確認。
  積雪無効・降雪量 0・融雪 0.5 では入力の平面と一致。
- 浮動小数 EXR の尾根地形で、風・降雪線・薄雪・移流・ノイズを併用し、有限な出力を確認。
- 設定とカーブの保存・読み込みを確認。
- `--screenshot-ui` でプロパティと Surface に接続した雪の被覆を撮影し、目視確認。
  検証データは `data/snow-cover-tests/`。
- Houdini 上での同一入力による比較は未実施。
