# nodes — ノードのリファレンス

作成日時: 2026-09-03 17:30
更新日時: 2026-09-03 17:30

ノード 1 つずつの、**役割・ピン・パラメータ**の一覧。

- 仕組み（データモデル、評価、エディタの操作）は [design/node-graph.md](../design/node-graph.md)。
- 合成規則とアルゴリズム（ハイトブレンド、川筋、堆積）は
  [design/compositing.md](../design/compositing.md)。
- ファイルに何が保存されるかは [file-format.md](file-format.md)。

## 線は 2 種類

| 線 | 何が流れるか | 繋げる先 |
| --- | --- | --- |
| **Material** | BaseColor / Normal / Surface / Height の 4 チャンネル一式 | Material 入力どうし |
| **Mask** | 0〜1 の 1 チャンネル | Mask 入力どうし |

同じ型どうししか繋がらず、循環する接続は弾かれる。入力ピンは 1 本だけ受け、
出力ピンは何本にでも分岐できる。

**ノード名とピンのラベルは英語**（Substance / Houdini / Gaea と語彙を合わせるため）。
説明とパラメータ名だけ日本語にしてある。

## 一覧

| ノード | 保存名 | 入力 | 出力 | 役割 |
| --- | --- | --- | --- | --- |
| **Heightmap** | `heightmap` | — | Result | 画像を地形として読み込む。**チェーンの起点** |
| **Surface** | `surface` | Base, Mask | Result | 素材を高さで張り合わせる |
| **Shape** | `shape` | Base, Mask | Result | 高さへ起伏を加算する |
| **Liquid** | `liquid` | Base, Mask | Result | 水位より低い所に水を張る |
| **Heightmap Blur** | `heightmapBlur` | Base | Result | ハイトをぼかしてならす |
| **Sediment** | `sediment` | Base | Result, **Mask** | 土砂を重力で再分配する |
| **Mask Image** | `maskImage` | — | Mask | 画像をマスクにする |
| **Mask Fluvial** | `maskFluvial` | Base | Mask | 下地の川筋をマスクにする |
| **Mask Slope** | `maskSlope` | Base | Mask | 下地の傾斜をマスクにする |
| **Mask Levels** | `maskLevels` | Mask | Mask | マスクの黒点 / 白点 / ガンマ |
| **Mask Blend** | `maskBlend` | Foreground, Background | Mask | マスク 2 枚を合成する |
| **Output** | `output` | Material | — | ここに繋いだチェーンが結果になる |

**Base 入力が繋がっていないノードは「一番下のレイヤー」**（下地）として扱われ、
マスクが効かない。合成する相手がいないため。

# 地形を作るノード

## Heightmap

画像 1 枚を地形として読み込む、**入力を持たないソース**。合成規則としては Shape
（高さへの加算）だが、下に何も無いので加算がそのまま地形になる。

**このノードだけが地形の実寸を持つ。** プレビューの平面のサイズと変位量は、
チェーンの根にあるこのノードに従う（プレビュー設定側の行は表示だけになる）。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 名前 | `Heightmap` | ノードの表示名 |
| ハイト / ソース | テクスチャ | 定数 / ノイズ / テクスチャ |
| ハイト / 画像 | なし | 読む画像と、そのチャンネル |
| ハイト / 持ち上げ | 0.50 | 0.5 で変化なし。上げると全体が浮く |
| スケール / サイズ | 1024.0 m | 地形の一辺。カメラと影の範囲もこれに追従する |
| スケール / 標高差 | 200.0 m | **ハイト 0〜1 の全幅が何 m か**（最低地点から最高地点までの差） |

- **`起伏の強さ` は持たない**（常に 1.0）。画像の 0〜1 がそのままハイトの全幅で、
  振れ幅は `標高差` が決める。同じ意味の値を 2 か所に置かないため。
- ハイトマップは**タイルせず 1 枚絵として**クランプで読む（wrap だと縁が混ざる）。
- マスクの行は出ない。下地がないので「どこに乗せるか」の意味がない。

## Surface

素材（マテリアル）を貼るノード。下地と**高さで競り合って**張り合わされる。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 名前 | `Layer` | |
| ベースカラー / ラフネス / メタルネス / AO | 0.18 / 0.5 / 0.0 / 1.0 | **マテリアル未割り当てのときだけ**出る |
| UV スケール | 1.00 | 模様を何回並べるか |
| ハイト / ソース | 定数 | 定数 / ノイズ / テクスチャ |
| ハイト / 基準の高さ | 0.50 | このレイヤーの「溜まる水位」。起伏の強さを変えても動かない |
| ハイト / 起伏の強さ | 1.00 | 基準の高さを中心とした凹凸の振れ幅。0 で平ら |
| マスク | （下の共通節） | どこに乗せるか |
| マテリアル | なし | 割り当てると色とサーフェスはマテリアル側で決まる |
| 合成 / 境界の柔らかさ | 0.15 | 0 に近いほど硬い置き換え |
| 合成 / 下地に沿わせる | 切 | 下地の形を保ったまま表面を被せる（コーティング） |
| 合成 / 書き込み | 全部 | BaseColor / Normal / Surface / Height のどれを書くか |

- **地形の上に素材を乗せるときは `下地に沿わせる` を入れる。** 切ったままだと
  勝った所の高さが自分の基準の高さになり、山の形が平らへ引き倒される。
  入れると「下地 + 相対的な起伏」になり、0.5 からのずれが被せ物の厚みになる。
- マテリアルの法線マップを持つときは、法線はマップから来る（ハイトの勾配は使わない）。
  規約の違い（OpenGL / DirectX）はマテリアル側の `緑を反転` で吸収する。

## Shape

高さへ**加算**するノード。競合しないので、下のレイヤーの細部がそのまま残る。
地形スケールの起伏（うねり、丘）を足すのに使う。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 名前 | `Shape` | |
| ハイト / ソース | ノイズ | 定数 / ノイズ / テクスチャ |
| ハイト / 画像 | なし | テクスチャのときだけ。**レイヤー直結**（マテリアルは使わない） |
| ハイト / 持ち上げ | 0.50 | 0.5 で変化なし |
| ハイト / 起伏の強さ | 0.60 | 加算する凹凸の振れ幅 |
| ハイト / ノイズ | fBm、スケール 3.0、オクターブ 5 | ソースがノイズのとき |
| マスク | （下の共通節） | 加算量の係数になる |

- **書き込むのは Normal と Height だけ。** 色とサーフェスは書かない（役割から外れるため）。
- 加算後に 0〜1 へ切り詰める。
- マスクは競合ではなく**加算量に掛かる係数**。0.5 なら半分の高さだけ足す。

## Liquid

水位より低い所に水面を張るノード。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 名前 | `Liquid` | |
| ベースカラー | (0.01, 0.03, 0.035) | 水中の散乱・吸収の色（赤が最も吸収される） |
| ラフネス / メタルネス / AO | 0.07 / 0.0 / 1.0 | |
| 水面 / 水位 | 0.35 | この高さより低い所に水面が張る |
| 水面 / フェザー | 0.010 | 汀線の柔らかさ。0 に近いほど硬い水際 |
| マスク | （下の共通節） | 水を張る範囲を絞る |

- **重みは「水位 − 下地の高さ」だけで決まる。** ハイトブレンドを通さないので、
  水位を動かしても下地は変形しない。
- UV スケールとマテリアルの行は出ない（模様を持たないため）。

## Heightmap Blur

下地のハイトをぼかす**加工**。合成はしない。ぼかした形から法線も作り直す。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 名前 | `Blur` | |
| 半径 | 3.00 m | ぼかす範囲。**実寸**なので合成解像度を変えても効きが変わらない |
| 強さ | 1.00 | 元の高さとぼかした高さを混ぜる量。1 で完全なぼかし |
| 反復 | 1 | 重ねる回数（実効半径はおよそ 半径 × √反復） |

- **下地になれない。** Base に何も繋がっていないと素通りする。
- 素材の法線ディテールを載せたいなら、**このノードより後ろに**サーフェスを繋ぐ
  （前に繋ぐと、作り直した法線で上書きされる）。
- マスクを取らない（Mask 入力を持たない）。

## Sediment

土砂を重力で再分配する加工。谷底に厚く積もり、尾根は痩せる。
**Result（地形）と Mask（積もった厚み）の 2 つを出す。**

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 名前 | `Sediment` | |
| 地形を土砂にする | 入 | 入なら入力の地形そのものが崩れる。切ると入力は動かない基盤になり、供給量で足したぶんだけが流れる |
| 供給量 | 0.50 m | 全体へ上乗せする土砂の厚み |
| 供給時間 | 0.00 | 0 で最初に全量。上げるほど反復に分けて積むので筋がはっきりする |
| 最大ディテール | 8.0 m | 1 反復でどこまで運ぶか。大きいほど広い盆地が早く落ち着くが重い |
| 粘性 | 0.20 | 安息角。0 で水平に均され、1 で 80 度まで留まる |
| 反復 | 40 | 崩し直す回数 |
| 安定化 | 2 | 1 反復のなかで滑らせる回数。粘性が低いときは上げると暴れにくい |
| 解像度 | 512 | 土砂を動かすグリッド。**合成解像度とは別** |
| 基準の厚み | 0.50 m | **Mask 出力がこの厚みで 1 になる。** 0 で「一番厚い所が 1」 |
| マスクの締まり | 0.00 | Mask 出力のコントラスト。0 で線形 |

- **積もった所では下の細かい凹凸が埋まる。** 厚みぶんだけ細部を 0 へ寄せるので、
  出っ張りの頂上は動かず、窪みが埋まり、厚く積もった所は平らになる。
- **Mask 出力の厚みは `基盤 + 土砂 − 元の高さ`**（削れた所は 0）。
  `地形を土砂にする` の入切どちらでも「積もったぶん」になる。
- `基準の厚み` を 0 にすると最大値で正規化するが、少数の分厚い点が基準になって
  残りが 0 付近へ潰れる。通常は実寸のまま使う。
- ブラーと同じく**下地になれない**。Base に何も繋がっていないと素通りする。
- **キャッシュが無い。** スタックが変わるたびに走る（既定値で 300 回ほどのディスパッチ）。

# マスクのノード

マスクは「そのレイヤーをどこに乗せるか」を外から与えるもの。レイヤーの Mask
入力へ繋ぐと、**白い所にだけ**そのレイヤーが乗る。

繋いだ先での効き方（`定数` の係数、`カーブ`、`レベル`、`反転`）は
**レイヤー側のマスクの節**で決める。ノードは値を作るところまでを受け持つ。

## Mask Image

画像 1 枚をマスクにする、入力を持たないソース。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 画像 | なし | 読む画像と、そのチャンネル（R / G / B / A） |

- 画像を入れていないマスクは「繋がっていない」のと同じ扱いになる
  （白 1 枚として全面に効かせると、繋いだ瞬間に絵が変わって驚くため）。

## Mask Fluvial

下地の**川筋**（水が集まる所）をマスクにする。Base 入力で「どこまで合成した
ハイトから作るか」を指す。繋がなければ、そのマスクを使うレイヤーの直下のハイト。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| カーブ | 対数 | 対数は細い支流まで見える / しきい値は川だけ抜く / 線形は主流が強い |
| しきい値 | 0.0000 | 川とみなす（または切り捨てる）流量。**全セル数に対する割合** |
| やわらかさ | 0.150 | しきい値のときだけ。境目をどれだけなだらかに繋ぐか |
| 川縁 | 1.60 | しきい値のときだけ。1 より大きいと川が細く、小さいと太い |
| ガンマ | 0.50 | 対数 / 線形のとき。下げると細い支流が明るくなる |
| 最大ディテール | 8.0 m | 流向を読む前にならす大きさ。大きいほど大きな谷筋を追う |
| 集中度 | 4.00 | 下流への配分の集中度。大きいほど主流へ集まる |
| 解像度 | 512 | 川筋を計算するグリッド。**合成解像度とは別** |

- **同じチェーンの上にあるノードだけ**を Base に指せる。別ブランチのハイトを
  読むにはノード単位の評価（DAG）が要る。チェーン外を繋ぐと「直下」に落ちる。

## Mask Slope

下地の傾斜を**角度（度）**でマスクにする。実寸で地形を扱うので、
「30 度より急な所」と意味の分かる単位で指定できる。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 最大ディテール | 0.0 m | 傾斜を測る距離。大きいほど小さな凹凸を無視して大きな斜面を拾う |
| 最小角 | 25.0 度 | これ以下の傾斜を 0 にする |
| 最大角 | 60.0 度 | これ以上の傾斜を 1 にする |
| ガンマ | 1.00 | 1 未満で弱い斜面を明るく、1 より大きいと急斜面だけを残す |
| 反転 | 切 | 平地のマスクを作るときに使う |

- `最大ディテール` は terrain-editor の「ぼかしてから勾配を取る」ではなく、
  **勾配を測る距離**にしてある（離れた 2 点の差を見るので小さな凹凸は自然に均される）。

## Mask Levels

入力のマスクを整える。細い川筋を太らせる、弱い成分を切り落とす、といった調整に使う。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 黒点 | 0.000 | これ以下を 0 にする |
| 白点 | 1.000 | これ以上を 1 にする。下げるほど早く飽和する |
| ガンマ | 1.00 | 1 未満で暗部を持ち上げ、1 より大きいと強い部分だけを残す |
| 反転 | 切 | |

- 入力が繋がっていないと意味を持たないので、そのときは「繋がっていない」扱いになる。

## Mask Blend

マスク 2 枚を合成する。**グラフが合流する唯一のノード。**

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 種類 | 乗算 | 加算 / 乗算 / 小さいほう / 大きいほう |
| 強さ | 1.00 | 前景そのままと合成結果の間の補間。0 で前景のまま |

- 乗算は絞り込み（両方が立つ所だけ）、加算は合算、
  小さいほう / 大きいほうは飽和させずに寄せる。
- **片方だけ繋いだときは、繋いだほうをそのまま通す**（未接続は 0 ではなく「中立」）。

# Output

出力ノード。**Material 入力へ繋いだチェーンが結果になる。**
プレビューも書き出しも、ここから遡ったチェーンを合成する。
パラメータは持たない。

- 出力ピンをクリック（またはノードをダブルクリック）すると、
  出力ノードではなく**そのノードまで**をプレビューできる。
  Mask の出力を選ぶと、そのマスクが白黒で貼られる。
- 何も繋がっていなければ下地 1 枚で補う。

# レイヤーノードに共通する設定

Surface / Shape / Liquid / Heightmap が共通で持つ節。

## 有効

切ると合成から外れる。ノードは残るので、繋ぎ替えずに効果を確かめられる。

## ハイト

| パラメータ | 意味 |
| --- | --- |
| ソース | 定数 / ノイズ / テクスチャ |
| 基準の高さ（持ち上げ） | このレイヤーの「溜まる水位」。Shape では「全体の持ち上げ」で 0.5 が変化なし |
| 起伏の強さ | 基準の高さを中心とした凹凸の振れ幅。0 で平ら |
| ノイズ | 種類（fBm / 尾根状 / セル状）、スケール、量、オクターブ、オフセット |

**ハイトは 0〜1 の正規化値。** 何 m かは Heightmap ノードの `標高差` が決める。
法線はこのハイトの**実寸の勾配**から作るので、強さのようなつまみは持たない。

## マスク

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| ソース | 定数 | 定数 / ノイズ / テクスチャ / 下地の高さ / 下地の傾斜 / 下地の曲率 / 下地の窪み / ペイント |
| 定数 | 1.00 | ソースの値に掛ける係数 |
| 画像 | なし | ソースがテクスチャのとき |
| 強調 | 1.00 | 下地から作るソース（高さ / 傾斜 / 曲率 / 窪み）のとき |
| カーブ | 1.00 | 1 で線形。大きいほど境界がはっきりする |
| レベル下限 / 上限 | 0.00 / 1.00 | 黒点 / 白点 |
| 反転 | 切 | |

- **Mask 入力にノードを繋ぐと、ソースはそちらに切り替わる**（行は「画像（Mask 入力）」の表示になる）。
  係数・カーブ・レベル・反転はそのまま効くので、ノードの結果をここで追い込める。
- マスクは**被覆率**。0 で乗らず、1 で全面を覆い、中間は
  **そのレイヤーの起伏の高い所から順に**出る。
- 一番下のレイヤー（Base 入力が繋がっていないノード）ではマスクが効かない。

## 合成（Surface のみ）

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 境界の柔らかさ | 0.15 | 0 に近いほど硬い置き換え |
| 下地に沿わせる | 切 | 下地の形を保ったまま表面を被せる |
| 書き込み | 全部 | BaseColor / Normal / Surface / Height のどれを書くか |

# ノードを増やすとき

手順は [design/node-graph.md](../design/node-graph.md) の
「ノードを 1 種類増やす手順」にある。**この一覧にも節を足すこと。**
