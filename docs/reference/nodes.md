# nodes — ノードのリファレンス

作成日時: 2026-09-03 17:30
更新日時: 2026-09-04 03:30

ノード 1 つずつの、**役割・ピン・パラメータ**の一覧。

- 仕組み（データモデル、評価、エディタの操作）は [design/node-graph.md](../design/node-graph.md)。
- 合成規則とアルゴリズム（ハイトブレンド、川筋、堆積）は
  [design/compositing.md](../design/compositing.md)。
- ファイルに何が保存されるかは [file-format.md](file-format.md)。

## 線は 3 種類

| 線 | 色 | 何が流れるか | 繋げる先 |
| --- | --- | --- | --- |
| **Material** | 緑 | BaseColor / Normal / Surface / Height の 4 チャンネル一式 | Material 入力どうし |
| **Mask** | オレンジ | 0〜1 の 1 チャンネル | Mask 入力どうし |
| **Path** | 薄い紫 | 地形の上に引いた向き付きの線（点とエッジ） | Path 入力どうし |

ピンの丸と線の色は型で決まる。**繋ぎ間違いは色で気づける。**

同じ型どうししか繋がらず、循環する接続は弾かれる。入力ピンは 1 本だけ受け、
出力ピンは何本にでも分岐できる。

**ノード名とピンのラベルは英語**（Substance / Houdini / Gaea と語彙を合わせるため）。
説明とパラメータ名だけ日本語にしてある。

## 一覧

| ノード | 保存名 | 入力 | 出力 | 役割 |
| --- | --- | --- | --- | --- |
| **Heightmap** | `heightmap` | — | Result | 画像を地形として読み込む。**チェーンの起点** |
| **Surface** | `surface` | Base, Mask | Result | 素材を高さで張り合わせる |
| **Shape** | `shape` | Base, Mask | Result | 高さへ起伏を加算する |
| **Liquid** | `liquid` | Base, Mask | Result | 水位より低い所に水を張る |
| **Heightmap Blur** | `heightmapBlur` | Base | Result | ハイトをぼかしてならす |
| **Sediment** | `sediment` | Base | Result, **Mask** | 土砂を重力で再分配する |
| **Crumbling** | `crumbling` | Base, Emission | Result, **Mask**, **Unique** | 岩屑を斜面下へ流して積む |
| **Snow** | `snow` | Base | Result, **Mask** | 雪を降らせ、急な雪面から落として積もらせる |
| **River** | `river` | Base, Seed | Result, **Water**, **Bank**, **Depth** | 川筋から河床を掘り、下流へ下がる水面を張る |
| **Mask Image** | `maskImage` | — | Mask | 画像をマスクにする |
| **Mask Noise** | `maskNoise` | — | Mask | ノイズをマスクにする |
| **Mask Fluvial** | `maskFluvial` | Base | Mask | 下地の川筋をマスクにする |
| **Mask Height** | `maskHeight` | Base | Mask | 下地の標高帯（m）をマスクにする |
| **Mask Slope** | `maskSlope` | Base | Mask | 下地の傾斜をマスクにする |
| **Mask Curvature** | `maskCurvature` | Base | Mask | 下地の凹凸（尾根 / 谷）をマスクにする |
| **Mask Levels** | `maskLevels` | Mask | Mask | マスクの黒点 / 白点 / ガンマ |
| **Mask Blend** | `maskBlend` | Foreground, Background | Mask | マスク 2 枚を合成する |
| **Path** | `path` | Base | Path | 地形の上に線を引く（ビューポートで編集） |
| **Mask Path** | `maskPath` | Path | Mask | パスの足跡をマスクにする |
| **Output** | `output` | Material | — | ここに繋いだチェーンが結果になる |

**Base 入力が繋がっていないノードは「一番下のレイヤー」**（下地）として扱われ、
マスクが効かない。合成する相手がいないため。

# 地形を作るノード

## Heightmap

画像 1 枚を地形として読み込む、**入力を持たないソース**。合成規則としては Shape
（高さへの加算）だが、下に何も無いので加算がそのまま地形になる。

**このノードだけが地形の実寸を持つ。** プレビューの平面のサイズと変位量は、
チェーンの根にあるこのノードに従う（プレビュー設定側の行は表示だけになる）。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 名前 | `Heightmap` | ノードの表示名 |
| ハイト / ソース | テクスチャ | 定数 / ノイズ / テクスチャ |
| ハイト / 画像 | なし | 読む画像と、そのチャンネル |
| ハイト / 持ち上げ | 0.50 | 0.5 で変化なし。上げると全体が浮く |
| スケール / サイズ | 1024.0 m | 地形の一辺。カメラと影の範囲もこれに追従する |
| スケール / 標高差 | 200.0 m | **ハイト 0〜1 の全幅が何 m か**（最低地点から最高地点までの差） |

- **`起伏の強さ` は持たない**（常に 1.0）。画像の 0〜1 がそのままハイトの全幅で、
  振れ幅は `標高差` が決める。同じ意味の値を 2 か所に置かないため。
- ハイトマップは**タイルせず 1 枚絵として**クランプで読む（wrap だと縁が混ざる）。
- マスクの行は出ない。下地がないので「どこに乗せるか」の意味がない。

## Surface

素材（マテリアル）を貼るノード。下地と**高さで競り合って**張り合わされる。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 名前 | `Layer` | |
| ベースカラー / ラフネス / メタルネス / AO | 0.18 / 0.5 / 0.0 / 1.0 | **マテリアル未割り当てのときだけ**出る |
| UV スケール | 1.00 | 模様を何回並べるか |
| ハイト / ソース | 定数 | 定数 / ノイズ / テクスチャ |
| ハイト / 基準の高さ | 0.50 | このレイヤーの「溜まる水位」。起伏の強さを変えても動かない |
| ハイト / 起伏の強さ | 1.00 | 基準の高さを中心とした凹凸の振れ幅。0 で平ら |
| マスク | （下の共通節） | どこに乗せるか |
| マテリアル | なし | 割り当てると色とサーフェスはマテリアル側で決まる |
| 合成 / 境界の柔らかさ | 0.15 | 0 に近いほど硬い置き換え |
| 合成 / 下地に沿わせる | 切 | 下地の形を保ったまま表面を被せる（コーティング） |
| 合成 / 書き込み | 全部 | BaseColor / Normal / Surface / Height のどれを書くか |

- **地形の上に素材を乗せるときは `下地に沿わせる` を入れる。** 切ったままだと
  勝った所の高さが自分の基準の高さになり、山の形が平らへ引き倒される。
  入れると「下地 + 相対的な起伏」になり、0.5 からのずれが被せ物の厚みになる。
- マテリアルの法線マップを持つときは、法線はマップから来る（ハイトの勾配は使わない）。
  規約の違い（OpenGL / DirectX）はマテリアル側の `緑を反転` で吸収する。

## Shape

高さへ**加算**するノード。競合しないので、下のレイヤーの細部がそのまま残る。
地形スケールの起伏（うねり、丘）を足すのに使う。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 名前 | `Shape` | |
| ハイト / ソース | ノイズ | 定数 / ノイズ / テクスチャ |
| ハイト / 画像 | なし | テクスチャのときだけ。**レイヤー直結**（マテリアルは使わない） |
| ハイト / 持ち上げ | 0.50 | 0.5 で変化なし |
| ハイト / 起伏の強さ | 0.60 | 加算する凹凸の振れ幅 |
| ハイト / ノイズ | fBm、スケール 3.0、オクターブ 5 | ソースがノイズのとき |
| マスク | （下の共通節） | 加算量の係数になる |

- **書き込むのは Normal と Height だけ。** 色とサーフェスは書かない（役割から外れるため）。
- 加算後に 0〜1 へ切り詰める。
- マスクは競合ではなく**加算量に掛かる係数**。0.5 なら半分の高さだけ足す。

## Liquid

水位より低い所に水面を張るノード。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 名前 | `Liquid` | |
| ベースカラー | (0.01, 0.03, 0.035) | 水中の散乱・吸収の色（赤が最も吸収される） |
| ラフネス / メタルネス / AO | 0.07 / 0.0 / 1.0 | |
| 水面 / 水位 | 0.35 | この高さより低い所に水面が張る |
| 水面 / フェザー | 0.010 | 汀線の柔らかさ。0 に近いほど硬い水際 |
| マスク | （下の共通節） | 水を張る範囲を絞る |

- **重みは「水位 − 下地の高さ」だけで決まる。** ハイトブレンドを通さないので、
  水位を動かしても下地は変形しない。
- UV スケールとマテリアルの行は出ない（模様を持たないため）。

## Heightmap Blur

下地のハイトをぼかす**加工**。合成はしない。ぼかした形から法線も作り直す。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 名前 | `Blur` | |
| 半径 | 3.00 m | ぼかす範囲。**実寸**なので合成解像度を変えても効きが変わらない |
| 強さ | 1.00 | 元の高さとぼかした高さを混ぜる量。1 で完全なぼかし |
| 反復 | 1 | 重ねる回数（実効半径はおよそ 半径 × √反復） |

- **下地になれない。** Base に何も繋がっていないと素通りする。
- 素材の法線ディテールを載せたいなら、**このノードより後ろに**サーフェスを繋ぐ
  （前に繋ぐと、作り直した法線で上書きされる）。
- マスクを取らない（Mask 入力を持たない）。

## Sediment

土砂を重力で再分配する加工。谷底に厚く積もり、尾根は痩せる。
**Result（地形）と Mask（積もった厚み）の 2 つを出す。**

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 名前 | `Sediment` | |
| 地形を土砂にする | 入 | 入なら入力の地形そのものが崩れる。切ると入力は動かない基盤になり、供給量で足したぶんだけが流れる |
| 供給量 | 0.50 m | 全体へ上乗せする土砂の厚み |
| 供給時間 | 0.00 | 0 で最初に全量。上げるほど反復に分けて積むので筋がはっきりする |
| 最大ディテール | 8.0 m | 1 反復でどこまで運ぶか。大きいほど広い盆地が早く落ち着くが重い |
| 粘性 | 0.20 | 安息角。0 で水平に均され、1 で 80 度まで留まる |
| 反復 | 40 | 崩し直す回数 |
| 安定化 | 2 | 1 反復のなかで滑らせる回数。粘性が低いときは上げると暴れにくい |
| 解像度 | 512 | 土砂を動かすグリッド。**合成解像度とは別** |
| 基準の厚み | 0.50 m | **Mask 出力がこの厚みで 1 になる。** 0 で「一番厚い所が 1」 |
| マスクの締まり | 0.00 | Mask 出力のコントラスト。0 で線形 |

- **積もった所では下の細かい凹凸が埋まる。** 厚みぶんだけ細部を 0 へ寄せるので、
  出っ張りの頂上は動かず、窪みが埋まり、厚く積もった所は平らになる。
- **Mask 出力の厚みは `基盤 + 土砂 − 元の高さ`**（削れた所は 0）。
  `地形を土砂にする` の入切どちらでも「積もったぶん」になる。
- `基準の厚み` を 0 にすると最大値で正規化するが、少数の分厚い点が基準になって
  残りが 0 付近へ潰れる。通常は実寸のまま使う。
- ブラーと同じく**下地になれない**。Base に何も繋がっていないと素通りする。
- **Result を繋がず、Mask だけ使ってもよい。** その場合はこのノードが
  下地に合流する所へ自動で差し込まれて走り、**Height へは書き戻さない**
  （繋いでいない出力は結果に効かせない）。地形は変えずにマスクだけ取れる。
  - ただし**下地が本流と合流していること**。まったく別のチェーンに置くと
    結果が残らず、マスクが無いのと同じ扱いになる。
    その状態のときはプロパティに注意書きが出る。
- **キャッシュが無い。** スタックが変わるたびに走る（既定値で 300 回ほどのディスパッチ）。

## Crumbling

発生源の明るい所から**岩片**を生み、地形の低い方へ歩かせ、止まった位置に岩片の形を
積む加工。崖下のガレ場（スクリー）を作るためのもの。

**Emission 入力が発生源。** Mask Slope で急斜面を作って繋ぐのが基本形。
繋がなければ全面から生む。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 名前 | `Crumbling` | |
| 岩屑の量 | 0.65 | 生む岩片の数と、盛り上がりの強さに効く |
| 最小サイズ | 2.00 m | 岩片の直径の下限 |
| 最大サイズ | 8.00 m | 岩片の直径の上限 |
| 形 | 尖った破片 | 丸い（ドーム）/ 多面体（6 角）/ 尖った破片（4 角） |
| 歩数 | 48 | 岩片を下へ進めるステップ数。大きいほど斜面の下まで流れる |
| 重力 | 0.75 | 低い方へ向かう強さ。高いほど一直線に下る |
| 散らばり | 0.35 | 進行方向から横へ逸れる強さ。上げると筋状の重なりがほぐれる |
| シード | 0 | 発生位置とばらつきの種 |

- **Mask 出力は岩屑の厚み**（岩片の形そのもの）。ガレ場へ別のマテリアルを乗せるのに使う。
- **Unique 出力は岩片ごとの乱数**（0〜1）。岩 1 個ずつで色や粗さを変えたいときに使う。
  岩屑が無い所は 0。
- 岩片の数は**地形の面積に比例**する（1km 四方あたりの数として持つ）。
  terrain-editor は解像度によらない固定数だが、実寸で扱うここでは
  同じ量でも 1km 四方と 4km 四方で密度が変わってしまうため。
- ブラーや堆積と同じく**下地になれない**。Base に何も繋がっていないと素通りする。
- **Result を繋がず、Mask / Unique だけ使ってもよい**（堆積と同じ扱い）。
  その場合は Height へ書き戻さないので、岩屑の分布だけが取れる。
- **粒子どうしを押し分ける処理は持たない**（terrain-editor にはある）。
  1 スレッド 1 粒子で走らせるため、全粒子を見渡す分離パスと相性が悪い。
  重なりが気になるときは `散らばり` を上げる。

## Snow

雪を一様に降らせ、**雪面**（下地 + 積雪厚）が安息角より急な所から、
**一番急な下り 1 方向**へ滑らせる加工。谷・棚・緩い尾根に溜まり、
急な岩肌には残らない。

**Result（雪を積んだ地形）と Mask（雪の被覆）の 2 つを出す。**

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 名前 | `Snow` | |
| 積雪量 | 1.00 m | 地形へ降らせる雪の総量。0 なら入力をそのまま通す |
| 供給時間 | 0.00 | 0 で最初に全量。上げるほど段に分けて降らせるので、溜まる所がはっきりする |
| 安息角 | 35.0 度 | **雪面**がこれ以下の傾斜なら雪は動かない。下げるほど急な所に残らない |
| 流動率 | 0.45 | 1 回の滑らせで動く割合。高いほど急斜面から早く逃げる |
| 雪面のならし | 0.25 | 積もった雪面だけをならす強さ。0 で切る |
| 最大ディテール | 8.0 m | 雪が移動先を探す最大の距離。ならしの半径にも使う |
| 反復 | 40 | シミュレーションの段数 |
| 安定化 | 4 | 1 段のなかで雪を滑らせる回数 |
| 解像度 | 512 | 雪を動かすグリッド。**合成解像度とは別** |
| 被覆のしきい値 | 0.02 m | **Mask 出力がこの積雪厚で白へ寄る** |
| 被覆のぼかし | 0.015 m | 積雪境界のグレーの幅。0 に近いほど二値に近い |

- **堆積との違いは行き先の数。** 土砂は安息角を超えた 4 近傍すべてへ配るが、
  雪は**一番急な 1 方向**へ寄る。片側へ吹き寄せたような積もり方はこれで出る。
  もう 1 つの違いは、雪は下地を削らないこと（必ず上に乗る）。
- **安息角は雪面の角度で、地形の角度ではない。** 積もるほど雪面は寝るので、
  同じ地形でも「積雪量が増えるほど、より急な所まで残る」。
- **滑らせは歩幅を粗いほうから細かいほうへ落としていく**（`最大ディテール` から
  1 セルまで半分ずつ）。1 セルずつしか動かさないと、広い斜面で雪が下まで
  届くのに段数が要る。
- 積もった所では下の細かい凹凸が埋まる（堆積と同じ扱い）。
- ブラーや堆積と同じく**下地になれない**。Base に何も繋がっていないと素通りする。
- **Result を繋がず、Mask だけ使ってもよい**（堆積と同じ扱い）。
  Height へ書き戻さないので、地形は変えずに雪の分布だけが取れる。
- **キャッシュが無い。** スタックが変わるたびに走る
  （既定値で 320 回ほどのディスパッチ）。
- terrain-editor には `Backend`（CPU / GPU）の切り替えがあるが、こちらは
  GPU だけにした（合成そのものが GPU なので、落とす先が無い）。

## River

川筋（フロー累積）から幅を決めて**河床を掘り、下流へ単調に下がる水面を張る**加工。
盆地は出口の高さまで埋まって湖になる。設計の経緯と却下した案は
[river-node.md](river-node.md)。

**Result（河床を掘って水を張った地形）と、Water（水面の被覆）/ Bank（河原）/
Depth（水深）の 3 つの Mask を出す。** Seed 入力（省略可）は雨の量で、
川の出どころを絞る。繋がなければ全面に一様に降る。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 名前 | `River` | |
| 川のしきい値 | 0.0020 | 川とみなす流量。**全セル数に対する割合**（Mask Fluvial と同じ単位） |
| 最大ディテール | 8.0 m | 流向を読む前にならす大きさ |
| 集中度 | 4.00 | 下流への配分の集中度。大きいほど主流へ集まる |
| 解像度 | 512 | 川筋を計算するグリッド。**合成解像度とは別** |
| 主流の幅 | 60.0 m | **流量が最大のセル**での川幅。幅の基準はここ |
| 最小幅 | 3.0 m | しきい値ぎりぎりの細い沢でも、これより細くしない |
| 幅の伸び | 0.50 | 流量に対する幅の指数。0.5 が水理幾何の標準、0 で一定幅 |
| 河床の深さ | 3.0 m | 川の中心での水面から河床まで。水際へ向けて U 字に浅くなる |
| 岸の幅 | 8.0 m | 水際から岸の上端までの距離。岸は水面の高さから立ち上がる（**掘る形**の話） |
| 岸の硬さ | 0.35 | 0 でなだらかな土手、1 で切り立った崖 |
| 水を張る | 入 | 切ると乾いた河床のまま残す（涸れ川）。Water / Depth の Mask は出る |
| 最小勾配 | 0.0002 | 水面が下流へ下がる最小の傾き。大きくすると平坦な谷底が上流側から浸かる |
| 河原の広がり | 15.0 m | 水際から外側へ、河原とみなす距離。主流での値で、支流は幅と同じ比で縮む |
| 河原の比高 | 2.0 m | 水面からこの高さまでを河原とする（増水時に浸かる帯） |
| 河原のぼかし | 0.30 | 河原の縁のなだらかさ。広がりと比高それぞれに対する割合 |

- 幅は `max(最小幅, 主流の幅 × (Q / Qmax)^幅の伸び)`。基準を主流側に置くので、
  しきい値を動かしても幅が暴れない。**見える水の幅はこの値そのもの**（岸は水面の
  高さから立ち上がるので水没しない）。支流をもっと細くしたければ `幅の伸び` を
  1.0 に近づけるのが一番効く（0.5 だと主流の 1/10 の流量でも幅は 3 割残る）。
- `Seed` は雨の量。Mask Height で高い所だけ白にすれば山地から出る川だけが残り、
  ペイントで数か所塗ればそこが源流になる。雨の総量が減るので `川のしきい値` は
  下げて合わせること。**湖は Seed に関係なく出る**（地形の窪みから決めるため）。
- **水の Surface には Height / Normal を書かせない**（チャンネルを BaseColor /
  Surface だけにする）。水面の形と法線は River が決める。Surface のハイトを
  通すと、平らな水面の上でそれが揺れる。水の質感の推奨値は
  [compositing.md の「リキッド」](../design/compositing.md)。
- **`Bank` → `Crumbling` の Emission** に繋ぐと、河原に岩片の形を積める。
  急な岸だけに置くなら `Bank × Mask Slope`（Mask Blend の乗算）。
- `Depth` を Mask Levels で反転すれば浅瀬のマスクになる。
- 水面の法線は R32 の水面高から作る（合成の Height は R16 で、緩い水面は約 0.3 m の
  階段になるため）。Height 自体の階段は残るので、緩い水面をごく低い角度から見ると
  段が見えることがある。
- **順序は Sediment → River。** River の後ろに Sediment を置くと、水面を地形として
  見るので岸の土砂が水面の上に溜まる。
- 出ないもの: 蛇行、内側湾曲の砂州、河岸段丘、滝。**湖岸には Bank が出ない**
  （河原は川の中心線からの距離で決めるため。予定は river-node.md の段階 2）。
- ブラーや堆積と同じく**下地になれない**。Base に何も繋がっていないと素通りする。
- **Result を繋がず、Mask だけ使ってもよい**（堆積と同じ扱い）。
- **キャッシュが無い。** スタックが変わるたびに走り、**いまのノードで一番重い**
  （512 で約 2100 回のディスパッチ。窪み埋め 1024 + 流量 1024 + JFA 10 + 数回）。
  川筋の形は粗いグリッドでも決まるので、**調整中は 256、仕上げで 512**。

# マスクのノード

マスクは「そのレイヤーをどこに乗せるか」を外から与えるもの。レイヤーの Mask
入力へ繋ぐと、**白い所にだけ**そのレイヤーが乗る。

繋いだ先での効き方（`定数` の係数、`カーブ`、`レベル`、`反転`）は
**レイヤー側のマスクの節**で決める。ノードは値を作るところまでを受け持つ。

**Mask の出力ピンをクリックすると、そのマスクが白黒でプレビューに出る。**
貼る先は 2 通りで、マスクの性質で自動的に決まる。

| マスク | 貼る先 |
| --- | --- |
| Mask Image / Mask Noise（下地を見ない） | **平らな板** |
| Mask Fluvial / Mask Height / Mask Slope / Mask Curvature / 堆積 / 崩落 / 積雪 / 河川（下地を見る） | 地形 |
| Mask Levels / Mask Blend | 入力を辿って上のどちらかに従う |

下地を見ないマスクを地形に貼ると、起伏の陰影に紛れて濃淡が読めない。
逆に川筋や傾斜は、地形との対応こそが見たいものなので地形の上に貼る。

**プレビュー設定の `マスクの飽和に斜線` を入れると、0 か 1 に張り付いた所へ
斜線が出る。** 濃淡が付いている所と、上限に当たって潰れた所は絵では
見分けが付かない。反転しても絵が変わらない、といった場合はここを疑う。

## Mask Image

画像 1 枚をマスクにする、入力を持たないソース。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 画像 | なし | 読む画像と、そのチャンネル（R / G / B / A） |

- 画像を入れていないマスクは「繋がっていない」のと同じ扱いになる
  （白 1 枚として全面に効かせると、繋いだ瞬間に絵が変わって驚くため）。

## Mask Noise

ノイズ 1 枚をマスクにする、入力を持たないソース。**下地に依らない**ので、
他のマスクを崩したり、領域をランダムに区切ったりするのに使う。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 種類 | fBm | fBm / 尾根状 / セル状 |
| 周波数 | 6 | 大きいほど細かい模様。**整数へ丸めて使う** |
| 量 | 1.00 | 0.5 を中心にした振れ幅。1 でノイズそのもの、0 で一様な 0.5 |
| オクターブ | 5 | 重ねる段数。多いほど細部が増える |
| オフセット | 0.0 | 同じ設定で別の模様がほしいときにずらす（terrain-editor の Seed に当たる） |

- **出力は必ずタイルする**（周波数を整数へ丸め、格子を折り返して評価するため）。
- 合成レイヤーのマスクにも同じノイズが「ノイズ」ソースとして入っている。
  ノードにすると、1 枚のノイズを Mask Blend で複数の場所へ配れる。
- terrain-editor の Mask Noise は Perlin fBM 1 種類で、
  `Lacunarity` / `Persistence` を持つ。こちらは**種類を 3 つ持つ代わりに
  その 2 つを 2.0 / 0.5 に固定**してある（合成レイヤーのノイズと同じ実装を使うため）。

## Mask Fluvial

下地の**川筋**（水が集まる所）をマスクにする。Base 入力で「どこまで合成した
ハイトから作るか」を指す。繋がなければ、そのマスクを使うレイヤーの直下のハイト。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| カーブ | 対数 | 対数は細い支流まで見える / しきい値は川だけ抜く / 線形は主流が強い |
| しきい値 | 0.0000 | 川とみなす（または切り捨てる）流量。**全セル数に対する割合** |
| やわらかさ | 0.150 | しきい値のときだけ。境目をどれだけなだらかに繋ぐか |
| 川縁 | 1.60 | しきい値のときだけ。1 より大きいと川が細く、小さいと太い |
| ガンマ | 0.50 | 対数 / 線形のとき。下げると細い支流が明るくなる |
| 最大ディテール | 8.0 m | 流向を読む前にならす大きさ。大きいほど大きな谷筋を追う |
| 集中度 | 4.00 | 下流への配分の集中度。大きいほど主流へ集まる |
| 解像度 | 512 | 川筋を計算するグリッド。**合成解像度とは別** |

- **同じチェーンの上にあるノードだけ**を Base に指せる。別ブランチのハイトを
  読むにはノード単位の評価（DAG）が要る。チェーン外を繋ぐと「直下」に落ちる。

## Mask Height

下地の**標高帯**をマスクにする。「350m から上」のように高さで素材を分けるためのもの。
Base 入力の意味は Mask Slope と同じ。

**0 m は地形の一番低い所**（ハイト 0）で、**`標高差` m が一番高い所**（ハイト 1）。
ハイトは 0〜1 の正規化値なので、実寸の基準は Heightmap ノードの `標高差` が決める。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 全範囲 | 切 | 地形の**実際の**最低を 0、最高を 1 にする。下の 3 つは使わない |
| 最低標高 | 0.0 m | これより低い所を 0 にする |
| 最高標高 | 1000.0 m | これより高い所を 0 にする |
| フェザー | 0.0 m | 標高帯の上下の境目をぼかす幅。0 で硬い帯になる |
| ガンマ | 1.00 | 1 未満で境目の弱い所を明るく、1 より大きいと帯の中心だけを残す |
| 反転 | 切 | 指定した標高帯の外側のマスクを作るときに使う |

- **既定値は「全面が白」**（0m 〜 1000m）。繋いだ瞬間に絵が変わって驚かないよう、
  何もしないところから始める。使うときは `最低標高` を上げる。
- `全範囲` は**地形の実データの最低 / 最高**で正規化するので、
  「一番低い所から一番高い所までのグラデーション」になる。
  `最低標高 = 0` / `最高標高 = 標高差` とは違う（画像が 0〜1 を使い切っていない
  ことがあるため）。焼くときに最低 / 最高を集計する 2 パスが増える。
- ガンマは**傾斜 / 曲率と同じ向き**（`pow(値, ガンマ)`）。terrain-editor は
  `1 / ガンマ` だが、隣り合うノードでつまみの向きが逆だと混乱するので揃えた。
- 雪線を引くなら `フェザー` を広めに、段々畑のような硬い帯なら 0 にする。
  Mask Slope と Mask Blend（乗算）で組むと「高くて急な所」を抜ける。

## Mask Slope

下地の傾斜を**角度（度）**でマスクにする。実寸で地形を扱うので、
「30 度より急な所」と意味の分かる単位で指定できる。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 最大ディテール | 0.0 m | 傾斜を測る距離。大きいほど小さな凹凸を無視して大きな斜面を拾う |
| 最小角 | 25.0 度 | これ以下の傾斜を 0 にする |
| 最大角 | 60.0 度 | これ以上の傾斜を 1 にする |
| ガンマ | 1.00 | 1 未満で弱い斜面を明るく、1 より大きいと急斜面だけを残す |
| 反転 | 切 | 平地のマスクを作るときに使う |

- `最大ディテール` は terrain-editor の「ぼかしてから勾配を取る」ではなく、
  **勾配を測る距離**にしてある（離れた 2 点の差を見るので小さな凹凸は自然に均される）。

## Mask Curvature

下地の**凹凸**をマスクにする。周りの平均の高さと比べて、高い所（尾根・出っ張り）か
低い所（谷・窪み）を拾う。Base 入力の意味は Mask Slope と同じ。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 向き | 両方 | 尾根 / 谷 / 両方 |
| 最大ディテール | 8.0 m | 比べる周りの広さ。大きいほど小さな凹凸を無視して広い尾根や谷を拾う |
| 感度 | 1.00 m | この高さの差で 1 になる。小さいほど弱い曲率まで明るくなる |
| しきい値 | 0.00 | これ以下の弱い曲率を捨てる |
| ガンマ | 1.00 | 1 未満で弱い曲率を明るく、1 より大きいと強い所だけを残す |

- **ラプラシアンではなく「周りの平均との差」**。だから「どのくらいの広さの周りと
  比べるか」を実寸（m）で指定できる。感度も m なので、地形の標高差を変えても
  効き方が変わらない。
- 「尾根」と「谷」は**排他**で、「両方」はその和になる（実測で完全に一致）。
- レイヤーのマスクにある `下地の曲率` は**別物**（ラプラシアン、無次元の強調度）。
  実寸で調整したいときはこのノードを使う。
- 周りの平均は、同心円 4 本のリング（32 点）を半径で重み付けして近似する。
  terrain-editor は箱ぼかしを 1 枚作ってから引くが、半径が 64 テクセルまで
  伸びるとまともに畳めない。高さは滑らかなので、この近似で同じ絵になる。

## Mask Levels

入力のマスクを整える。細い川筋を太らせる、弱い成分を切り落とす、といった調整に使う。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 黒点 | 0.000 | これ以下を 0 にする |
| 白点 | 1.000 | これ以上を 1 にする。下げるほど早く飽和する |
| ガンマ | 1.00 | 1 未満で暗部を持ち上げ、1 より大きいと強い部分だけを残す |
| 反転 | 切 | |

- 入力が繋がっていないと意味を持たないので、そのときは「繋がっていない」扱いになる。

## Path

地形の上に引いた**向き付きの線**。道路 / 川 / 氷河のような「方向のあるもの」の
ガイドで、**ビューポートで編集する**（グラフでこのノードを選ぶと、ビューポートの
左クリックがパスの編集になる。ステータスバーに「パス編集中」が出る）。

- **点は地形平面の位置（正規化 UV）だけを持ち、高さは持たない。** 高さは読む側が
  入力の地形から毎回導く。上流の侵食を触っても線は地面に沿い続ける
  （設計の経緯は [design/node-graph.md の「パス」](../design/node-graph.md)）。
- Base 入力は「どの時点の地形に沿うか」。**評価には効かない**（座標は 2D なので）。
  このノードをダブルクリックすると Base に繋いだ地形がプレビューになり、
  その上で編集できる。
- エッジは from → to の向きを持つ（線に矢印で出る）。川や氷河では流れの向き、
  道路では無視してよい。分岐は自由（支流の合流、道路の交差）。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 幅 | 24 m | 新しく置く点の幅。マスクではこの幅の内側が 1 |
| フェザー | 12 m | 新しく置く点のフェザー。幅の外側をこの距離で 0 へ |
| 強さ | 1.00 | 新しく置く点のマスクの強さ |
| 選択した点の 幅 / フェザー / 強さ / 高さのずれ | — | 選んだ点だけの値。複数選んでいれば全部に入る |

**ビューポートの操作**

| したいこと | 操作 |
| --- | --- |
| 伸ばす | 何もない所をクリック（末尾の点から新しい点へ。末尾が無ければ新しい線の始点） |
| 選ぶ / 続きの起点にする | 点をクリック（末尾になり、仮のエッジがカーソルへ伸びる） |
| 途中に点を足す | エッジをクリック（そのままドラッグできる） |
| 動かす | 点をドラッグ（地形の表面に沿う） |
| 繋ぐ | 点を別の点や線へドラッグして重ねる（吸着して結合。Shift で吸着なし） |
| 切る | 点を右クリック → 分離（エッジの本数ぶんに分ける）、エッジを右クリック → 削除 / 切り離す |
| 向き | 点やエッジを右クリック → 向きを反転、または点を選んで R |
| 消す | 点を選んで Delete |
| 線を区切る | Enter / Esc（末尾を解除。次のクリックは新しい線の始点） |
| 視点 | Alt + ドラッグ（ペイントと同じ） |

## Mask Path

Path の線を、**点ごとの幅とフェザー**でマスクにする。中心線から幅の半分までは 1、
その外側をフェザーの距離で 0 へ落とす。エッジ上では両端の値を補間し、
線どうしが重なる所は強いほうを取る。エッジの無い孤立した点は円になる。

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| ガンマ | 1.00 | フェザーのカーブ。1 未満で外側まで明るく、1 より大きいと中心へ締まる |
| 反転 | 切 | 白黒を入れ替える |

- 形（幅 / フェザー / 強さ）は Path の点が持つ。ここは調整だけ。
- 下地のハイトは読まないが、プレビューは**地形の上に貼る**（線と地形の対応こそが
  見たいもの）。
- River の Seed に繋げば、川をどこから流すかを線で指定できる。

## Mask Blend

マスク 2 枚を合成する。**グラフが合流する唯一のノード。**

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 種類 | 乗算 | 加算 / 乗算 / 小さいほう / 大きいほう |
| 強さ | 1.00 | 前景そのままと合成結果の間の補間。0 で前景のまま |

- 乗算は絞り込み（両方が立つ所だけ）、加算は合算、
  小さいほう / 大きいほうは飽和させずに寄せる。
- **片方だけ繋いだときは、繋いだほうをそのまま通す**（未接続は 0 ではなく「中立」）。
- 堆積 / 崩落 / 積雪の Mask を入力にすると、**そのノードが走るチェーンまで遡って**
  プレビューする（出どころがチェーンの外にいると結果が残らないため）。
  プレビューの地形が「そのノードまで合成した状態」になるのはこのため。

# Output

出力ノード。**Material 入力へ繋いだチェーンが結果になる。**
プレビューも書き出しも、ここから遡ったチェーンを合成する。
パラメータは持たない。

- 出力ピンをクリック（またはノードをダブルクリック）すると、
  出力ノードではなく**そのノードまで**をプレビューできる。
  Mask の出力を選ぶと、そのマスクが白黒で貼られる。
- 何も繋がっていなければ下地 1 枚で補う。

# レイヤーノードに共通する設定

Surface / Shape / Liquid / Heightmap が共通で持つ節。

## 有効

切ると合成から外れる。ノードは残るので、繋ぎ替えずに効果を確かめられる。

## ハイト

| パラメータ | 意味 |
| --- | --- |
| ソース | 定数 / ノイズ / テクスチャ |
| 基準の高さ（持ち上げ） | このレイヤーの「溜まる水位」。Shape では「全体の持ち上げ」で 0.5 が変化なし |
| 起伏の強さ | 基準の高さを中心とした凹凸の振れ幅。0 で平ら |
| ノイズ | 種類（fBm / 尾根状 / セル状）、スケール、量、オクターブ、オフセット |

**ハイトは 0〜1 の正規化値。** 何 m かは Heightmap ノードの `標高差` が決める。
法線はこのハイトの**実寸の勾配**から作るので、強さのようなつまみは持たない。

## マスク

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| ソース | 定数 | 定数 / ノイズ / テクスチャ / 下地の高さ / 下地の傾斜 / 下地の曲率 / 下地の窪み / ペイント |
| 定数 | 1.00 | ソースの値に掛ける係数 |
| 画像 | なし | ソースがテクスチャのとき |
| 強調 | 1.00 | 下地から作るソース（高さ / 傾斜 / 曲率 / 窪み）のとき |
| カーブ | 1.00 | 1 で線形。大きいほど境界がはっきりする |
| レベル下限 / 上限 | 0.00 / 1.00 | 黒点 / 白点 |
| 反転 | 切 | |

- **Mask 入力にノードを繋ぐと、ソースはそちらに切り替わる**（行は「画像（Mask 入力）」の表示になる）。
  係数・カーブ・レベル・反転はそのまま効くので、ノードの結果をここで追い込める。
- マスクは**被覆率**。0 で乗らず、1 で全面を覆い、中間は
  **そのレイヤーの起伏の高い所から順に**出る。
- 一番下のレイヤー（Base 入力が繋がっていないノード）ではマスクが効かない。

## 合成（Surface のみ）

| パラメータ | 既定 | 意味 |
| --- | --- | --- |
| 境界の柔らかさ | 0.15 | 0 に近いほど硬い置き換え |
| 下地に沿わせる | 切 | 下地の形を保ったまま表面を被せる |
| 書き込み | 全部 | BaseColor / Normal / Surface / Height のどれを書くか |
