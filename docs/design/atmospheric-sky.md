# 大気散乱スカイと雲

作成日時: 2026-09-09 13:36
更新日時: 2026-09-09 14:59

## 操作と互換性

「ライティング > モード」で「環境マップ (IBL)」と「大気散乱スカイ」を切り替える。
既定は環境マップ。従来の HDRI / 簡易生成天球の選択、輝度、ぼかし、ライブラリ操作は維持する。
大気散乱では専用の太陽・大気設定を編集でき、「雲を描画」でボリューム雲を有効にする。
雲量・消散係数・雲底・厚さ・ノイズスケール・存在範囲の中心 X/Z・雲の分布半径・境界フェード幅・シード・品質を調整できる。
アニメーションをオンにすると風向・風速で雲模様が流れる。オフで一時停止し、存在範囲は固定する。
風向は進行方向で 0 度が +Z、90 度が +X。既定は停止、風速 10 m/s、上限 1000 m/s。
移動量は実行時のみ保持し、新規・プロジェクト読み込みでリセットする。

太陽設定と生成環境はモードごとに別に持ち、従来モードへ戻せば元の天球とライトを使う。
露出・トーンマップ・影・背景表示は共通の表示設定。影を切ると雲影も切れる。
チャンネルのデバッグ表示では空・雲を描かず、シェーディングとクレイで有効にする。
天球アセットのプレビュー窓は従来の天球を表示し、マテリアルのプレビュー窓は有効な照明を使う。

`.tgproj` の `preview.lightingMode` に `ibl` / `atmospheric` を書く。
`preview.atmosphere` に専用太陽・大気・雲を保存し、既存の `preview.light` は従来のライトのまま保持する。
追加フィールドのない旧プロジェクトと未知のモード名は `ibl` として読む。
読み込み時に数値の範囲を制限し、「新規」で両モードの設定を既定へ戻す。
加算的なフィールドなのでファイル形式の版番号は変更しない。

## UI の用語

ゲームエンジンで一般的な用語を使い、見た目への効果はツールチップで説明する。
UE 固有の仕様や数値への互換性を意味しない。

| 表示名 | 内部設定と意味 |
| --- | --- |
| レイリー散乱強度 | `density`。レイリー散乱係数の倍率 |
| ミー密度 | `mie`。ミー散乱と吸収の共通倍率。散乱強度だけではない |
| ミー異方性 | `eccentricity`。大気のミー散乱の異方性 g |
| 地表の基準標高 | `altitude`。地形原点の海抜高度 |
| グラウンドアルベド | `groundAlbedo`。下半球の反射輝度を近似する係数 |
| 消散係数 | `extinction`。雲の光の減衰（1/m） |
| ノイズスケール | `cloudScale`。雲模様の水平周期（m） |
| 雲の分布半径 | `fieldRadius`。雲の存在範囲の半径（m） |
| 境界フェード幅 | `fieldFalloff`。外縁の密度減衰幅（m） |

今回の名称変更では計算と保存キーを変更しない。

## 移植元と統合

`D:/GitHub/terrain-editor/shaders/atmosphere.hlsli`、`atmosphere_multiscatter.hlsl`、
`cloud_density.hlsl` と `cloud_render.hlsl` の散乱・周期密度・レイマーチを基にした。
Nishita 系の単散乱と Hillaire 系の多重散乱 LUT を使う近似モデル。
名称は [Unreal Engine の Sky Atmosphere](https://dev.epicgames.com/documentation/en-us/unreal-engine/sky-atmosphere-component-in-unreal-engine)
に対応させた。厳密なスペクトル大気シミュレーションではない。

- 新しい GPU リソースの所有は `renderer::Atmosphere` にまとめ、既存 RHI / DXC / SM 6.6 / bindless へ載せ替えた。
- 生成した空と雲を 512×256 の環境マップへ焼き、既存の irradiance / GGX prefilter / BRDF LUT を使う。
  移植元の半球 ambient に置き換えず、既存 PBR の環境光・反射へ接続する。
- 太陽ディスクは背景だけに描く。環境マップにはディスクを入れず、太陽を直接光と二重計上しない。
- 照度は大気圏外の lux（既定 120000）、空は照度に比例する線形 HDR。
  太陽の色と地表での照度は大気透過率から求め、露出は最後の既存トーンマップだけで掛ける。
- マテリアル照明の太陽透過率は CPU、空・雲の透過率は HLSL。
  地球半径・散乱係数・密度分布・8 点の太陽方向積分を揃える。変更時は両方を確認する。

## 移植時の修正

- 観測高度 500m の固定を廃止し、海抜の「基準標高」を設定にした。
  環境マップと背景は同じ基準高度を使い、カメラ移動で再生成しない。
  雲との交差には実際のカメラ座標を使う。
- 色を青寄りに補正する地平線の後処理を除去。
  下半球は上半球を地面反射率で減衰する近似とし、地平線で連続に接続する。
- 太陽光路の途中をサンプルするだけでなく、地球との交差で太陽の遮蔽を明示的に判定。
- 視線の光学深度を積分点の中央で評価。多重散乱 LUT は高度の二乗配置にして地表近傍へ解像度を割く。
- 移植元の独自線形深度を使わず、逆ビュー射影行列から透視投影の距離を復元。
  地形より先にある雲は積分しない。雲内からの視線にも対応。
- 周期 Perlin fBM の密度生成は維持し、64³ の密度を 64 枚の 2D 配列へ格納。
  XY は GPU のバイリニア補間、Z は 2 スライスの線形補間で、周期境界も連続。
- 雲影と自己遮蔽は共通の有限円柱交差・密度・透過率を使う。太陽方向の出口まで品質に応じて 16〜256 点を積分する（標準 32〜128 点）。
  移植元の専用影テクスチャと投影範囲に依存せず、直接光だけを減衰する。
- 雲は HDR 合成し、既存の被写界深度・トーンマップへ渡す。

## 更新と負荷

大気 LUT は密度変更時、雲密度はシード変更時だけ生成する。
環境マップは太陽・大気・雲設定の変更時に更新する。
アニメーション時は雲本体と地形の雲影に同じ移動量を毎フレーム渡し、環境マップは最大 1 Hz で更新する。
そのため環境光と反射の雲には最大約 1 秒の遅れがある。再生成時の同期 GPU 待ちは残る。
背景の散乱結果もキャッシュし、毎画素での大気レイマーチを避ける。
同じ設定ならモードを往復しても生成し直さない。

雲の視線方向サンプルは低 32 / 標準 64 / 高 128 を基準に、斜めの長い光路では最大 4 倍。
密度は区間中央、区間内の透過率は Beer-Lambert の解析式で積分する。
雲の存在範囲はワールド座標の有限円柱で、視点距離による密度フェードは使わない。
既定は雲底 1500 m・厚さ 2000 m・ノイズ周期 4000 m・範囲半径 6000 m・減衰幅 2000 m。
既存ファイルの保存済み寸法は保持し、新しい範囲設定がなければ既定値を補う。雲の見え方は変更される。
画面解像度と品質に応じて描画負荷が上がる。
生成処理は現在の `Environment` と同じくフレーム外の `ExecuteImmediate` で完了させるため、
太陽や設定の連続編集時には GPU 待機が入る。非同期更新・時間分割は今後の改善余地。

## 近似と現在の範囲

- 雲は一層の密度移流。雲の発生・消滅の気象シミュレーション、複数の雲種、時間再投影は未対応。
- 雲の環境照明は雲層中央の上下半球を各 32 方向で平均し、各点の上下方向の透過率で遮蔽を近似する。
  天頂 1 点と固定の明るさ下限は使わない。ただし方向ごとの入射輝度と遮蔽を完全には積分していない。
- 太陽の位相関数は前方 HG（g=0.8）と後方 HG（g=-0.3）を 0.8:0.2 で混合。
  各ローブの球面積分は 1、混合後も 1。水滴の厳密な Mie 位相関数ではない。
- 多重散乱は 4 オクターブで近似し、高次ごとに重み・消散・方向性を 0.5 倍にする。
  パストレーシングによるエネルギー収支の検証は未実施。地形の直射影には多重散乱項を混ぜない。
  参考: [Unity HDRP の公式雲実装](https://github.com/Unity-Technologies/Graphics/blob/master/Packages/com.unity.render-pipelines.high-definition/Runtime/Lighting/VolumetricClouds/VolumetricCloudsUtilities.hlsl)。
- 雲量の閾値処理後の密度は残りの範囲を 0〜1 に正規化する。雲量 0 は密度 0。
  消散係数は雲本体・自己遮蔽・地形影で共通。以前の同じ設定値でも雲と影は濃くなる。
- 環境光と反射の雲は地形原点からの遠景近似。局所的な反射の視差までは再現しない。
- 背景の太陽ディスクには RGBA16F の上限に合わせた輝度制限がある。
- 空気遠近法、オゾン吸収、月・星は今回の対象外。
- 地面反射と雲の多重散乱は近似。大気モデルの完全な物理精度を保証するものではない。
