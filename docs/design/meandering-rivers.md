# Meandering Rivers

作成日時: 2026-09-11 06:31
更新日時: 2026-09-11 06:34

`Meandering Rivers` HDA の静的調査を参考に、蛇行と河床生成の中核を
terrain-graph の GPU バッチ評価へ移植したノード。表示名は **Meandering Rivers**、
保存名は `meanderingRivers`。Houdini 上の実行結果との一致は検証していない。
元 HDA の調査は [参考資料](../reference/ktt-meandering-rivers.md)。

## 入出力と使い方

| ピン | 型 | 意味 |
| --- | --- | --- |
| Base | Material 入力 | Heightmap 等から来る地形。Height と実寸を使用する |
| Path | Path 入力 | 上流から下流へ向く、独立した開いた線 |
| Result | Material 出力 | 流域を整形し、蛇行した河床を掘った地形 |
| River | Mask 出力 | 河床の範囲。中央が 1、岸で 0 へ滑らかに変化する |

Heightmap の Result を Base に、Path ノードの Path を Path に接続する。
Path の Base にも同じ Heightmap を接続すると、入力の地形上で川筋を編集できる。
Meandering Rivers の Result を Output へ繋ぐ。河床に色や材質を付ける場合は、
Result の後ろに Surface 等を置き、その Mask に River を繋ぐ。

River だけを別の材質枝で使うこともできる。同じ下地から分岐する場合、川筋の計算を
チェーンへ差し込むが、その枝では地形に書き戻さない。無効なノードの River は 0。
Base が無い場合は既存のハイト加工と同じ中立平面、Path が無い場合は地形をそのまま返す。

## パラメータ

| 項目 | 既定値 | 意味 |
| --- | --- | --- |
| 反復回数 | 128 | 0〜512。0 は蛇行を進めず入力の川筋を使う |
| 川幅 | 5 m | 河床の全幅。Path 側の幅は使わない |
| 蛇行スケール | 1 | 初期標本間隔と 1 回の移動量に使う倍率 |
| 蛇行の強さ | 1 | 移流の倍率。0 は初期の揺らぎと反復を止める |
| 地形の影響 | 1 | 低い方へ向かう強さ |
| 平滑化 | 0.5 | 反復ごとの隣接点による平滑化 |
| 深さの比率 | 0.1 | 川幅に対する掘り込み深さ。0 は掘り込まない |
| 岸の揺らぎ | 0.1 | 道のりに沿った幅の変化率 |
| シード | 1 | 初期の微小変位と幅の揺らぎの乱数 |
| 上り勾配を除去 | 有効 | Path の矢印方向へ基準高を累積最小値にする |
| 流域を整形 | 有効 | 入力の川筋周辺を基準高へ馴染ませる |
| 流域の半幅 | 100 m | 初期川筋から流域外縁までの距離 |
| 流域の深さ | 0 m | 流域の基準高を下げる量 |

深さの比率を 0 にしても、流域を整形が有効なら地形は変わる。
地形を変えずに川筋の範囲だけを利用する場合は、River だけを接続する。
流域は高さをブレンドするため、掘削だけでなく盛り上がる場所もある。

## 計算

1. Path の曲線・経路の内部点を折れ線化し、向きをエッジの矢印に揃える。
   `川幅 × 蛇行スケール × 2` m を目安に等間隔化する。
2. 入力地形から標高を読み、Path の高さオフセットを加える。
   上り勾配除去が有効なら、各川の上流から下流へ累積最小値を取る。
3. 初期川筋からの距離で流域をブレンドする。反復中の勾配はこの流域から取得する。
4. 端点を固定して、`normalize(接線 − 地形勾配 × 地形の影響 × 標本間隔)` へ移流する。
   平滑化と道のりによる再サンプリングを繰り返す。近傍の同時更新は ping-pong で分離する。
5. 最終川筋を流域へ投影し直し、必要なら上り勾配を再度除去する。
   距離・幅・深さから河床を掘り、Height から法線を再生成する。

距離場は線分を種にする Jump Flood と最終の 1 セル補正で求める近似。
画素ごとに全線分を走査しないため、大きな地形でも計算量を抑えられる。
河床の最小半幅は約 0.707 セル。解像度を変えると細い川の見え方も変わる。

## HDA との差分と制限

- 対応は独立した開いた川筋。閉路、分岐、エッジの向きが途中で反転する Path は評価しない。
  孤立点や長さがほぼ 0 の鎖は川筋にしない。該当する入力ではプロパティに案内を表示する。
- 標本は 1 本あたり最大 256 点、全体で最大 2048 点。合計上限超過は評価せず、
  部分的な川を黙って出さない。反復中は標本数を固定するため、長い川の細部には制限がある。
- 高さは Follow Terrain 相当。Explicit / Sink to Terrain の選択、幅・強さのランプ、
  HDA の複数段のノイズや流域のぼかしは同一実装ではない。
- **蛇行後の Path 出力、三日月湖の切り離し、旧河道の履歴・年代・地形への刻印、
  Solver のフレーム進行とディスクキャッシュは未対応。**
- 境界外へ移動する点は地形の端へ制限する。自己交差する川筋は切り離さない。
  流体の質量保存、堆積、水面メッシュの生成は行わない。
- 元 HDA の完全再現ではなく、既存の地形・マスク評価器で使える中核機能の移植。

## 検証

- Debug / Release ビルドと既存テストを実行。
- グラフの接続、マスクだけの分岐、端点・高さオフセット・逆向き、空の Path、閉路をテスト。
- HLSL の 12 エントリポイントを DXC / SM 6.6 で単体コンパイル。
- Debug の GPU ベースバリデーションで描画と River マスクを確認。
- 反復 0 と 64 の描画、河床、Path 未接続、プロパティ UI を目視確認。
- 設定と名称の保存・読み込み、および再読み込み前後の描画一致を確認。
- 2048² のテクスチャ 6 枚（Height は EXR）の書き出しを確認。

確認用データは `data/meandering-qa/`、Release 実行ファイルは
`build/meandering/Release/terrain_graph.exe`。
