# プロジェクトルートと共有アセット

作成日時: 2026-09-13 20:32
更新日時: 2026-09-13 20:32

## 所有関係

プロジェクトは実フォルダをルートに持つ。開発環境では`data/`（`TG_DATA_DIR`で変更可能）を初期値とし、`--root`または「ルートフォルダを開く」で変更する。ルート直下の`project.tgproj`は`terrain-graph.workspace`版1のJSONで、プロジェクトIDと開始シーンを保持する。既存の同名ファイルが別形式なら上書きせず開く操作を中止する。

シーンは`.tgscene`（`terrain-graph.scene`版1）としてルート内の任意の場所に保存する。保存ダイアログの初期値は`Scenes/`。グラフ、プレビュー設定、使用中の天球、ペイントマスクの参照をシーンに保持する。ペイントは引き続き`<シーン名>.assets/`に保存し、キャッシュとは区別する。

画像とFBXは元のファイルを使う。ルート内のファイルはコピーせず、外部から読み込むファイルは選択フォルダへコピーする。旧シーンの保存時に外部参照を取り込む場合は`Imported/`へコピーする。再配布できない素材をリポジトリの`assets/`へ入れない。

## アセット形式

| 拡張子 | format | 内容 |
| --- | --- | --- |
| `.tgmat` | `terrain-graph.material-asset` | 名前、PBRパラメータ、画像のID参照 |
| `.tgsky` | `terrain-graph.sky-asset` | 名前、大気散乱、HDRIのID参照、環境光倍率 |
| `.tgmodel` | `terrain-graph.model-asset` | 名前、FBXのID参照、マテリアルスロットのID参照 |
| 元ファイル名`.meta` | `terrain-graph.source` | 元画像・FBXの固定ID |

すべてUTF-8 JSON、版1。マテリアル・天球・モデル設定は編集内容の原本であり、再生成可能なキャッシュではない。フォルダ分類は強制しない。旧シーンから初めて分離するときだけ`Materials/`、`Skies/`、`Models/`を使う。

モデル設定はFBXのサイドカーへ埋め込まず、独立した`.tgmodel`にした。同一FBXに異なるマテリアル割り当てを持つ旧シーンがあるため、設定の異なるモデルを安全に分離するためである。

参照は`{"uid":"固定ID","path":"ルート相対パス"}`。ネイティブ形式は内部にIDを持ち、元画像・FBXは隣の`.meta`にIDを保存する。ルート走査でIDから現在のパスを解決し、IDが見つからない場合に同名の別アセットへ黙って付け替えない。重複IDもエラーにする。原本をエクスプローラで移動するときは`.meta`も一緒に移動する。ネイティブ形式をエクスプローラで単純コピーするとIDも重複するので注意する。

この分離は[Unityのアセットメタデータ](https://docs.unity.cn/Manual/AssetMetadata.html)および[GodotのUID](https://godotengine.org/article/uid-changes-coming-to-godot-4-4/)を参考にする。シーン内のグラフは既存の整数IDを保ち、シーン内の参照表を介して永続IDへ接続する。GPU用の実行時IDと永続IDを混同しない。

## 保存と読み込み

「保存」はシーンと読み込み済み共有アセットを保存する。「アセットを保存」は共有アセットのみ保存する。新規マテリアル・天球は選択フォルダへ作成する。共有アセットを編集すると、それを参照する他シーンは次回読み込み時に更新された内容を使う。シーン切り替え前には保存・破棄・キャンセルを選べる。

旧`.tgproj`・`.mmproj`は既存の読み込み器で開く。通常の保存は別名の`.tgscene`へ行うため、移行元は残る。既存の持ち出し用`.tgmat`と新しい共有アセットはformatで区別する。同名の異なる旧マテリアルを名前だけで自動統合しない。

新シーンはアセットのJSONと依存参照を展開・検証してからGPU資源と現在の文書を置き換える。共有アセット欠落時は読み込みを中止し、現在の文書を保持する。画像そのものが欠け、メタデータが残る場合は既存のリンク切れ表示を使う。保存はファイル単位の一時ファイルと置換で保護する。複数ファイル全体を一括で巻き戻すトランザクションではない。

## UIと残る範囲

アセット帯は単一パネル。左に実フォルダのツリー、右にサブフォルダとアセットの84px格子を表示する。`.meta`とドットで始まる内部フォルダは隠す。ダブルクリックで読み込み・編集、モデルは従来どおりシングルクリックでプレビューする。読み込み済み画像とマテリアルは従来のドラッグペイロードを使用する。

現段階では明示的な「更新」で外部のファイル変更を取り込む。未読み込みアセットは種類名を表示し、開くとプレビューを作る。全アセットの自動サムネイル生成、ファイル監視、検索・種類フィルタ、ブラウザ内の移動・改名・削除は後続とする。フォルダ自体はエクスプローラで整理できる。
