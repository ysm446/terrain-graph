# Mask Flowline

作成日時: 2026-09-10 22:12
更新日時: 2026-09-10 22:12

地形の斜面に沿って粒子を移動させ、通過量をマスクとして蓄積する。地形の高さやジオメトリは変更しない。

## 入出力

| ピン | 型 | 動作 |
| --- | --- | --- |
| Base | Material 入力、必須 | 流れを計算する地形の高さと実寸スケール |
| Source | Mask 入力、任意 | 発生位置の粒子の強さに乗算。未接続は 1 |
| Outflow | Mask 入力、任意 | 通過後の強さを `saturate(1 - Outflow)` 倍に減衰。未接続は 0 |
| Mask | Mask 出力 | 流跡の累積値 |

追加メニューのマスク系から選ぶ。Base が未接続なら評価対象にならない。選択時のプレビューは Base の地形を使用する。

## 設定

- 発生方法は本数または密度。本数の既定値は 1,000。密度の既定値は 0.01 で、粒子数は `解像度² × セル幅(m) × 密度` の切り捨て。
- 長さは移動距離の上限（既定 256 m）。1 ステップで 1 セル分移動する。
- 摩擦は速度の保持率を調整する。障害物の回避と回避量で速度の補正を追加する。
- 窪みに滞留が無効なら、四近傍すべてが高い場所で停止する。完全な平坦面では移動方向がないため停止する。
- 強さは通過ごとの加算量（既定 0.025）。流れの分散は累積マスクを勾配計算へ加える量（既定 0.025）で、地形自体は変えない。
- 最小傾斜と傾斜の遷移幅で、緩い斜面での加算を抑える。
- 発生値を制限は Source を 0〜1 に制限する。無効でも負値は 0 として扱う。
- 出力を圧縮は累積値 `v` を `v / (1 + v)` に変換する。最大値による正規化ではない。
- 流出域を加算は圧縮後に Outflow の値を加える。この場合、出力は 1 を超えることがある。

Outflow が 1 のセルでも、停止前の 1 回は加算する。Source は発生時にだけ参照するため、発生域の外にも流跡が伸びる。

## GPU 評価と制限

`CompositeFlowline.hlsl` の初期化、散布、移動、加算、仕上げの各パスで処理する。各ステップの移動中は累積マスクを固定し、通過セルへの加算を別バッファに集計してから反映する。加算パスは粒子数に応じて実行し、同じセルの集計値は一度だけ取り込む。

加算は 1/65,536 単位の固定小数で、極端な値はステップ・セルごとに約 65,536 で飽和させる。粒子数の上限は `min(解像度², 1,000,000)`、反復は最大 16,384 ステップ。高密度・長距離ほど評価に時間がかかる。セル幅が変わるため、プレビューと書き出しの解像度によって流跡が変化する。

設定と Source / Outflow の接続はプロジェクトへ保存する。高さ、入力マスク、設定の変更でキャッシュを更新する。

## 検証

- Debug / Release ビルド、グラフテスト、全 5 エントリポイントの DXC コンパイル。
- 描画と設定 UI、Debug の GPU 検証、保存・再読み込み。
- 高さの EXR 出力を無効時と比較し、地形が変わらないことを確認。
- 平坦面、強さ 0、黒い Source、傾斜 90 度では流跡を生成しないことを確認。Source、Outflow、長さ、密度、出力圧縮の違いを画像出力で確認。

検証用ファイルは `data/flowline-qa/`、更新版 Release は `build/flowline/Release/terrain_graph.exe`。
